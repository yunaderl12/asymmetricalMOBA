## 1. ゲームの全体像

### (1) ゲームの基本コンセプト

非対称マルチプレイの3Dアクションストラテジー。5人（勇者4人 + 魔王1人。勇者が4人に満たない場合は不足分をBOT勇者で補う）で30分の試合を行う。

ゲームのイメージ: 第五人格/Dead by Daylight × League of Legends/ポケモンユナイト

### (2) 試合のシチュエーション

勇者チームはマップ左上の「はじまりのまち」からスタートし、マップ右下の空に浮かぶ魔王の城を目指す。森・山・砂漠には魔物が自然に湧き、砂漠には魔王の塔（スポナー）が立つ。魔物は最終フェーズ（魔王Lv16）になると、勇者のまちを破壊しに向かう。両陣営は同じマップで戦う非対称対戦方式を採用している。

### (3) 勇者チームの目的と行動

- **目的**: 魔王城の中心にあるコアを破壊するか、魔王本体を倒すこと
- **行動**:
  - クラス（剣士/魔法使い/僧侶/重戦士）を選んでスキルセットを構築
  - はじまりのまちからマップ中央〜魔王城方向へ進軍
  - 道中の魔物を倒して経験値を稼ぎ、スキルをレベルアップ
  - 砂漠の塔（スポナー）を破壊して、塔からの魔物の湧きを止める（森・山・砂漠の自然湧きは止まらない。大経験値も得られる。序盤の目標として、破壊時にボーナスを付けて誘導する。ボーナスの内容は未定）
  - 仲間と連携して魔王城に攻め込む
- **勝利条件**: 以下のいずれかを達成
  - 魔王城コアの HP を 0 にする
  - 魔王本体の HP を 0 にする
- **設計方針**: 魔王は城内で最強のため、魔王が城外に出続けている場合を除き、勇者は城内で魔王と戦うかコアを破壊するかのどちらかを行う。勇者が成長しないと勝てない設計とし、開始直後の速攻勝利が起きないようにする（魔王のHP・城内の防衛手段の具体値は未定）

### (4) 魔王チームの目的と行動

- **目的**: 勇者の拠点「はじまりのまち」のコアを破壊すること
- **行動**:
  - 試合前に20スロットのデッキに魔物を編成（魔物は最終的に20種類用意する。現在は3種類のみ）
  - 試合開始前の1分間で5箇所のスポナーに魔物を割り当て
  - 試合中は魔王城のコアに触れることで俯瞰モードに移行し、戦況を見ながらスポナーに魔物を追加（コスト制限内、削除不可）
  - 城外にも出て直接戦闘に参加可能（MPドレインと、移動速度・攻撃力のデバフのリスクあり）
  - 100秒ごとにレベルアップ（最大Lv16、試合開始25:00に到達）、城を中心にした赤い空と渦雲が広がっていく
- **勝利条件**: はじまりのまちのコアの HP を 0 にする

### (5) 試合フロー

タイトル画面 → ロビー（勇者ロビー or 魔王ロビー） → マッチング → マッチロビー（1分準備） → 試合（最大30分） → リザルト → タイトルに戻る

### 勇者（Hero）仕様

#### 役職（クラス）4種

- **クラスの見た目**: 全クラスとも外部で作ったテクスチャ付きモデルに差し替え済み。持ち物は、剣士が右手の剣と左手の盾、魔法使いが右手の杖と左手のそばに浮かぶ本（FloatingHeldItem）、僧侶が右手の杖と左手の本、重戦士が右手の斧と左手の盾。魔王も外部で作ったモデル（王冠と長いローブ・マントの吸血鬼風。Resources/DemonKing/demon_king.fbx）で、右手に紫の結晶の剣を持つ。マントの背中側は腕に付けず胴について行く。見た目の大きさは 魔王 ＞ 重戦士 ＞ 剣士 ＞ 魔法使い ＝ 僧侶 ＞ ゴブリン（倍率の仮値は 魔王1.5 / 重戦士1.15 / 剣士1.05 / 魔法使い0.93 / 僧侶0.89 / ゴブリン0.70。HeroClassData.modelScale、MonsterData.modelScale、BalanceConfig.demonKingModelScale）。当たり判定の大きさは見た目に連動させず、共通のまま。どのモデルも Knight の骨格とアニメーションを共有し、関節の位置だけモデルごとに合わせる（ModelBoneFit）。作り方は ArtSource/characters/rig_tripo.py

- **成長値（レベル毎）**: クラスごとに異なる成長値に統一する（剣士は HP+12, Atk+2 など。全クラスの成長値の数値表は未作成）
- **防御の種類**: 物理防御（Df）と魔法防御（mDf）に分ける。物理攻撃（Atk系）にDf、魔法攻撃（mAtk系）にmDfを適用する。mDfはクラスの性格でDfと逆転させ、魔法使い・僧侶は魔法に強く、重戦士は魔法に弱い（魔物・魔王のmDfは未定）
- **ダメージ計算式**: ダメージ = 攻撃値 × K / (K + 防御値)。攻撃値は Atk（物理）または mAtk（魔法）、防御値は Df または mDf。K は調整定数（仮: K=20。スキル倍率・最低ダメージ・クリティカルの有無は未定）
- **通常攻撃（左クリック）**: クラスごとに次の仕様（射程・攻撃間隔の数値は未定）
  - 剣士: 近接単体攻撃（Atk）
  - 重戦士: 近接の大振り。近距離の範囲攻撃（Atk）
  - 魔法使い: 遠距離の魔法弾（mAtk）。白い芯・マゼンタ・青・紺が重なる涙滴形の炎で、丸い根元を先頭に尾をうねらせて飛ぶ（短い紺色の軌跡と粒も残す）。杖の宝石のあたりから照準点へ飛び、壁や地面に当たると消える
  - 僧侶: 中距離の光弾（mAtk、威力は控えめ）

#### スキル（5スロット）

- スロット 1〜4: 選択クラス専用（自動セット、変更不可）
- 消費リソース: 勇者のスキルはSPを消費する（MPは魔王専用。スキルごとの消費SPは未定）
- スロット 5: 自由枠（他クラス12個 + 共通4個 = 16個から1つ。パーティ内で同じスキルを複数人が選ぶことはできない。クラスの重複は可）
  - 魔法使いの自由枠の一覧には、魔法使いだけが選べる専用スキル Explosion も並ぶ（HeroClassData.exclusiveFreeSkills）。他のクラスの一覧には出ない
- **ワープ地点設定スキル（新規）**: 共通スキル（WarpPoint）として自由枠に追加する。地点がないときに使うと、その場所をワープ地点に設定する（消費SP・クールタイムなし）。設定できるのは、破壊済みスポナーより自陣側（はじまりのまち→魔王城の軸上で、最も奥の破壊済みスポナー以下）か、はじまりのまちの周囲（仮 半径20m）のみ。スポナーが1つも破壊されていない間は、まち周辺にしか設定できない。地点があるときに使うと詠唱5秒（仮）のあとワープし、地点は消える（次に使うと再設定）。詠唱中に動く（0.5m以上）・被弾・スタン・沈黙・死亡で中断。消費SP 20・クールタイム45秒（仮、移動完了時に消費）。移動するのは本人のみ。地点は死亡しても残る

- **スキル演出の共通方針**: 発動は「短い溜め（最長1秒）→ 発動 → 余韻」の流れで、大きい技ほど派手にする。クラスごとに色を決める（剣士は白銀と青）。SP とクールタイムは発動の瞬間に消費し、溜め中のスタン・沈黙・死亡で中断されたら消費しない。溜め中は他のスキルと通常攻撃を使えない。溜めの秒数は SkillData.castTime に置く。
- **1人称の腕と武器**: 自分の視点には、クラスのモデルから取り出した腕と武器を表示する（全クラス共通の仕組み）。壁にめり込まないよう、最後に重ねて描く。構えの位置は HeroClassData に置く。他のプレイヤーからは、今のアニメーションクリップとコードでの姿勢変更で動いて見える。
- **Slash（剣士）**: 前方の扇形にいる敵すべてに当たる（以前の「視線の先の1体」は廃止）。三日月形の斬撃が走り、当たると火花とヒットストップが入る。壁の向こうには当たらない。味方は巻き込まない。
  - 仮値: 溜め0.2秒（移動可）/ 射程3m / 扇の角度120度（SkillData.coneAngle）
- **Charge（剣士）**: 溜めのあと、向いている方向へ実際に突進する（以前は移動しなかった）。最初にぶつかった敵1体に当たり、衝撃の輪と閃光とともに止まる。誰にも当たらなければ射程の分だけ進んで止まる。壁に当たっても止まる。
  - 仮値: 溜め0.4秒（移動不可）/ 突進距離6m（range）/ 突進の速さ24m/s（SkillData.dashSpeed）
- **Whirlwind（剣士）**: 溜めのあと体ごと2回転し、周囲の敵すべてに1回ずつ当たる。円形の斬撃と衝撃の輪が広がる。
  - 仮値: 溜め0.5秒（移動不可）/ 半径5m（range）
- **Guard（剣士）**: 盾を構え、光の膜をまとう。効果中は攻撃を受けるたびに膜が光る。効果中も移動と攻撃はできる。
  - 仮値: 溜め0.15秒（移動可）/ Df 1.5倍 5秒は変更なし
- **Bash（重戦士）**: 溜めのあと盾を前に構えて前方へ高速で突っ込む。ぶつかっても止まらず進み、触れた魔王・魔物すべてに1回ずつ中ダメージを与えて、前へ大きく突き飛ばす（以前のスタン1秒は廃止）。壁や押せない敵にぶつかると止まる。押し飛ばしは MonsterData.hitReactionScale の影響を受け、0 の敵には効かない。コアとスポナーは動かない。
  - 仮値: 溜め0.25秒（移動不可）/ 突進距離8m（range）/ 突進の速さ22m/s（dashSpeed）/ 突き飛ばす距離9m（knockbackDistance）/ ダメージ35 / 消費SP12 / クールタイム6秒（以前は3秒。移動技になったため仮で延長）
- **Stomp（重戦士）**: 溜めのあと、通常ジャンプより高く跳んで斧を振り上げ、勢いよく急降下する。着地点の真下の敵には大ダメージ、周囲の敵には衝撃波で中ダメージ。直撃でも衝撃波でも、当たると低確率で3秒スタンする（以前のスロー-40% 2秒は廃止）。着地で衝撃の輪・閃光・土煙が広がり、着地点の地面が削れて、角ばった土のかけらが飛ぶ（削れない場所では代わりに赤熱したヒビが走り、冷めたあとしばらく残る）。
  - 仮値: 溜め0.2秒（移動不可）/ 跳ぶ高さ2.8m（leapHeight。通常ジャンプは約0.6m）/ 急降下24m/s（diveSpeed）/ 前への移動2m / 直撃の半径1.5m・ダメージ2倍の60（directHitMultiplier）/ 衝撃波の半径5m（range）・ダメージ30 / スタン確率15%（statusChance）/ ヒビが残る時間6秒+消えるまで1.6秒 / 消費SP20・クールタイム8秒は変更なし
- **Taunt（重戦士）**: 溜めのあと斧を掲げて身を反らし、前に踏み込んで吠える。周囲へ赤い衝撃の輪が広がる。効果は変更なし（賢い魔物のヘイトを上げる）。仮値: 溜め0.3秒（移動不可）
- **IronWall（重戦士）**: 動きは Guard と同じで、盾を構えて琥珀色の光の膜をまとう。効果は変更なし（Df 2倍 6秒）。仮値: 溜め0.15秒（移動可）
- 重戦士の演出の色は琥珀と赤熱（MeleeFx.Ember）。
- **Heal（僧侶）**: 溜めのあと杖を掲げ、照準の先の味方へ光を送る。相手の足元から光の柱が立つ。照準の先に味方がいなければ（敵や壁を狙っていても）自分を回復する。敵は回復しない。
  - 仮値: 溜め0.25秒（移動可）/ 射程8m（狙いの太さ半径0.5m）。回復量30・消費SP15・クールタイム2秒は変更なし
- **GroupHeal（僧侶）**: 溜めのあと足元から金色の輪を広げ、範囲内の味方全員（自分を含む）を回復する。回復した全員の足元に光の柱が立つ。敵は回復しない。
  - 仮値: 溜め0.45秒（移動不可）/ 半径6m。回復量20・消費SP30・クールタイム10秒は変更なし
- **Blessing（僧侶）**: 杖を味方へ向けて溜めると光の筋が飛び、相手が光の柱に包まれて Atk が上がる。照準の先に味方がいなければ自分にかかる。効果の間は相手の体のまわりに光の粒が立ちのぼる（他の人からバフ中だと分かる）。味方にかけると経験値共有の「支援」に数える。同じ相手へかけ直すと効果時間が伸びる（重ねがけはしない）。
  - 仮値: 溜め0.35秒（移動不可）/ 射程8m（Heal と同じ）。Atk 1.3倍 10秒・消費SP20・クールタイム15秒は変更なし
- **Smite（僧侶）**: 溜めのあと杖を振り下ろすと、照準の先へ天から細い光が突き刺さる。当たった敵に魔法ダメージと沈黙を与える。敵に当たらなければ、狙った地点に光が落ちるだけで、SPとクールタイムは消費する。味方は素通りする。
  - 仮値: 溜め0.3秒（移動可）/ 射程10m（狙いの太さ半径0.5m）。ダメージ25・沈黙2秒・消費SP18・クールタイム5秒は変更なし
- **Explosion（魔法使いの専用スキル）**: 5秒溜めて、狙った地面に大爆発を起こす。自由枠に入れて使う。
  - 溜め: 視線の先の地面に水色の魔法陣が開き（敵にも見える）、杖の宝石から魔法陣へ光の線が伸びて、溜まるほど細くなる。溜め中は移動できない（視点は動かせる）。スタン・沈黙・死亡で中断すると SP もクールタイムも消費しない。
  - 溜めの最後の0.9秒: 魔法陣から光の柱と白い炎が立ちのぼり、星がきらめく。
  - 爆発の瞬間: 画面が2コマだけ黒地に白い集中線になり、続いて色の反転と白飛びを経て、青みが1.5秒ほどで抜ける（近くにいる人の画面だけ。HUD はそのまま見える）。
  - 爆発: 紺の縁取りと青い筆の跡が入った白いドームが一気に広がり、白い輪が2本浮かぶ。地面を緑の衝撃波が走り、根元に煙が立つ。ドームは約1.8秒で透けて消え、そのあと黒いきのこ雲が立って約5.7秒で虫食い状に消える。
  - 破片: ボクセルの破片が吹き飛び、最初は宙にゆっくり舞ってから落ちる。5秒後に透明になって消える。
  - 着弾点の地面が大きく削れる（「地面を削る仕組み」を参照）。削れない場所では代わりにひび割れを残す。破片も角ばったかけらにする。
  - 仮値: 溜め5秒（移動不可）/ 射程30m / 半径9m（スキルレベルで広がる）/ 魔法ダメージ120 / 吹き飛ばし6m / 消費SP50 / クールタイム40秒。BOT は使わない
- **ManaShield（魔法使い）**: 溜めのあと全身が水色の六角の泡に包まれる。効果の間は移動も攻撃もできる。受けるダメージそのものを減らす（防御力は変えない）。被弾すると泡が光る。自分の画面では中央が透け、端だけが光る。
  - 仮値: 溜め0.2秒（移動可）。受けるダメージ 50%（スキルレベルごとに10%軽くなり Lv5 で 30%）。8秒・消費SP25・クールタイム20秒は変更なし

  - 仮値: 溜めなし。Spd 1.5倍 4秒・消費SP10・クールタイム15秒は変更なし
- **Recover（共通）**: 胸に手を当てて息を整えると、緑の光の柱に包まれて回復する（自分の画面では柱を出さず粒だけにする）。

- **Detect（共通）**: 手を耳元に上げると足元から水色の輪が広がり、範囲内の魔物と魔王の頭上に赤い菱形の印が付く。印は壁越しでも見え、使った本人の画面にだけ出る。魔王の探知スキルとは別物。

  - 仮値: 溜め1秒（castTime）/ 弾速28m/s（projectileSpeed）/ 射程15m（range）/ 溜め中は移動不可・視点は動かせる（castLocksMovement）/ 自分の弾が当たったときのヒットストップ0.06秒（hitStopSeconds）
  - 消費: SP とクールタイムは放った瞬間に消費する。スタン・沈黙・死亡で溜めが中断されたら消費しない。ダメージでは中断されない。溜め中は他のスキルと通常攻撃を使えない。
  - 当たり判定: 敵に当たるとダメージと灼熱を与える。味方はすり抜ける。壁と地面に当たると火花を出して消える（ダメージなし）。何にも当たらず射程まで飛ぶと、失速しながら小さくなって消える。
  - 演出: 溜めで勇者が反り、放つときに前へ踏み込む。飛翔中は涙滴形に伸び、短いトレイルと火の粉を残す。被弾した敵は2コマ真っ白になった後、炎の膜が0.5秒残る。見た目のモデルだけつぶれて押し込まれる（実際の位置は動かない）。
  - 自分の勇者モデルは1人称カメラに映らないため、本人にはカメラの動き（引き・FOV・揺れ）で同じ構えを見せる。
  - Phase 8 での注意: ヒットストップは Time.timeScale を使っており、ホストのゲーム全体に効く。ネットワーク化の際にクライアントの見た目だけの処理へ置き換える。
- **Teleport（はじまりのまちへの帰還）**: どこからでも、勇者の復活地点へ戻る魔法使いのスキル（以前の「前方へ10m移動」は廃止）。溜め5秒（仮）でゆっくりつぶれて光を吸い込み、細い光に伸びて消える。溜めの間に攻撃を受けると中止になり、SPは消費せずクールタイムも始まらない（スタン・沈黙でも同じ）。飛び立つと真上へ昇り（1.6秒）、上空でホバーしてまちの方を向き（0.8秒）、シアンの光の軌跡を残してまちへ降りて（2.5秒）、衝撃の輪と火花とともに着地する（いずれも仮値）。カメラも一緒に飛ぶ。クールタイムは30秒（仮）。
  - 仮値: 溜め5秒（SkillData.castTime）/ 上昇1.6秒（teleportRiseSeconds）/ ホバー0.8秒（teleportHoverSeconds）/ 移動2.5秒（teleportTravelSeconds）/ ホバーの高さ20m以上（距離に応じて高くなる、teleportArcHeight）/ 着地後の硬直0.3秒（teleportLandingSeconds）/ 消費SP20・クールタイム30秒
  - 消費: SP とクールタイムは飛び立つ瞬間に消費する。溜め中の被弾・スタン・沈黙・死亡で中断（消費なし）。
  - 飛行中: 当たり判定がなく操作もできない。継続ダメージで倒れた場合はそこで打ち切る。
- **Blizzard（狙った地点への氷）**: 視線の先の地面を狙う魔法使いのスキル（以前の「自分の周囲に範囲ダメージ」は廃止）。溜めの間は着弾点に輪を表示し、発射の瞬間の地点へ足元から氷柱の列が走る。氷柱は先へ行くほど大きく、両脇に外へ傾いた小さな氷柱が扇状に広がる。着弾点で大きな氷の塊が立ち上がり、閃光とカメラの揺れが入る。氷柱は少し残ったあと先端から溶けて砕け、冷気ときらめきが漂う。
  - ダメージ: 着弾点の範囲内の敵にだけ入る（氷柱の列は演出で当たり判定なし）。味方と自分は巻き込まない。ダメージとスローは氷が届いた瞬間に入る。
  - 氷の地面: 着弾点に残り、残る時間はスキルレベルで伸びる。上を歩くと敵も味方も自分も滑る（勇者・魔王・魔物・BOT すべて）。
  - 消費: SP とクールタイムは放つ瞬間に消費する。溜め中のスタン・沈黙・死亡で中断（消費なし）。被弾では中断されない。
  - 仮値: 溜め0.6秒 / 射程20m / 範囲の半径5m（SkillData.areaRadius）/ 氷の持続 Lv1で6秒、Lvごとに+2秒（Lv5で14秒、SkillData.duration・durationPerLevel）/ 氷柱の速さ40m/s（blizzardSpikeSpeed）/ 氷の上の加速度3m/s²（iceAcceleration）/ 消費SP30・クールタイム10秒・ダメージ25・スロー3秒40%は変更なし
- **スキル成長**: 最大Lv5、効果値 = 基礎値 × (1 + (Lv-1) × 0.2)（Lv5 で 1.8倍）
- **レベルによる凄み**: スキルレベルが上がると、効果の大きさが少しずつ増す。倍率は 1 + (Lv-1) × 0.1（Lv5 で 1.4倍、仮値。SkillData.sizeGrowthPerLevel）。
  - 当たる範囲も広がるもの: Slash の射程 / Whirlwind の半径 / Blizzard の着弾の半径と氷の地面 / Fireball の弾の大きさ / Stomp の衝撃波の半径 / Taunt の範囲 / GroupHeal の半径
  - 動きが強くなるもの: Stomp の跳ぶ高さと急降下の速さ / Bash の突き飛ばす距離
  - 見た目だけ大きくなるもの: Blizzard の氷柱 / Charge と Guard と IronWall の閃光や輪 / Teleport の着地の演出 / Heal と Blessing と Smite の光
- **スキルポイント**: 勇者レベルアップで +1 獲得、1〜5キーで割当て
- **状態異常（方針）**: 次の4種を用意する。同じ種類を重ねると上書きし、残り時間は長い方・効果量は強い方を採用する（重ねても強くならない）。耐性はスタンのみで、スタンが解けた後1.5秒はスタンにかからない（仮値）。スキルへの割り当て（仮値）: Stomp=スタン3秒（確率15%）/ Blizzard=スロー-40% 3秒 / Fireball=灼熱 3秒（毎秒3ダメージ） / Smite=沈黙2秒
  - スタン: 一定時間行動不能になる
  - スロー: 移動速度が低下する
  - 継続ダメージ（毒・灼熱）: 一定時間、毎秒ダメージを受ける
  - 沈黙: 一定時間スキルを使えない

#### パッシブ

クラスごとの選択肢から1つ選ぶ（ロビーのスキル欄の右に表示。選択肢は今後増やす）。僧侶と重戦士のパッシブは未定で、今は選択肢がない。BOT はパッシブを持たない。数値はすべて仮値で PassiveData に置く。

- **高速避け（剣士）**: A / D を素早く2回押すと、その方向へ短く滑る。SP は消費しない。無敵時間はない。
  - 仮値: 二度押しの間隔0.5秒以内 / 距離4.5m / 0.2秒 / クールタイム1.5秒
- **斬撃（剣士）**: このパッシブの間は、通常攻撃がボタンを離した瞬間に出る。すぐ離せば通常攻撃、1秒以上長押しして離せば通常攻撃の代わりに前方へ三日月形の斬撃を飛ばす（SPが足りなければ通常攻撃）。スキルや気絶で構えが解けたら、押し直すまで何も出ない。溜まると剣先が光る。撃った本人からは剣の軌道と同じ右上から左下への直線に見え、他の人から横に見ると三日月に見える。斬撃は敵を貫通し、壁や地面に当たると消える。味方には当たらない。
  - 仮値: 物理ダメージ 通常攻撃の3倍 / 消費SP8 / 弾速30m/s / 射程25m / 当たり判定の半径1.5m
- **ダブルジャンプ（魔法使い）**: 空中でジャンプを押すともう一度跳べる。足元に魔法陣が一瞬出て、そこから持ち上げられる。着地すると使えるようになる。
  - 仮値: 消費SP3 / 上昇速度6.5（通常のジャンプは5）
- **魔法陣ブロック（魔法使い）**: 魔法攻撃を受けると、攻撃の来た方向に六角形のセルでできた魔法陣が自動で出る。物理攻撃には反応しない。
  - 防御計算後のダメージが一定以下なら完全に防ぐ（ダメージ0）。超える大技は一切吸収せず、ダメージをそのまま受けて、魔法陣だけがセルごとに割れて飛び散る。
  - 魔法陣は発動から0.5秒で透明になって消える。同時に出せるのは1〜3個で、すべて出ている間に受けた魔法攻撃は素通しする。消えれば次の攻撃に使える（別の待ち時間はない）。
  - 自分の画面では小さく薄く表示する。
  - 仮値: 防げるダメージ15以下 / 消費SPなし / 同時1個、Lv7で2個、Lv14で3個

#### ステータス・成長

- レベルアップでクラスごとの成長値（HP・SP・Atk・mAtk・Df・mDf）が加算され、スキルポイント +1 を獲得
- 経験値分配: ラストヒット 100% / アシスト 50%（10秒以内のダメージ・バフ・デバフ寄与者）。さらに、魔物を倒した位置の近くにいて、その魔物との戦闘に参加した味方（攻撃、または回復・バフを行った味方）にも少量を共有する（参加していない味方には入らない）。共有は倒した位置から半径30m以内で、その魔物の経験値の25%（仮値）。ラストヒットもアシストも取っていないけれど、10秒以内にその戦闘の味方を回復した勇者が対象
  - 塔が倒した場合: 10秒以内に攻撃した勇者のうち最後に攻撃した勇者がラストヒット扱いになる。誰も攻撃していなければ経験値は誰にも入らない
  - 演出: 倒された魔物から金色の粒が散らばり、ラストヒットの勇者へ吸い込まれる（見た目だけで、経験値は倒した瞬間に入る）
- 必要 Exp = currentLevel × 100
- レベル上限: Lv20（累計19,000Expで到達。上限到達後の経験値の扱いは未定）

#### HP/MP/SP 自動回復システム

- **SP の回復**: SP は主に次の2つで回復する。自然回復はごく少量（魔王の MP は対象外）
  - **魔物に通常攻撃を当てる**: 当たるたびに最大SPの6%（仮、BalanceConfig.spPerBasicHit）。スキルの命中、魔王や塔への攻撃では回復しない
  - **はじまりのまちに戻る**: まちの中心から半径26m（仮、townRefillRadius）に入ると全回復
  - **自然回復**: 1.5秒ごとに最大SPの一定割合。1未満の端数はためておき、1になったら回復する（ManaComponent.RestoreFraction）。割合は HeroClassData.spCombatRegenRate（仮: 剣士・重戦士 0.25%、魔法使い・僧侶 0.4%）
- **発火条件（増えていく回復）**: 攻撃も被攻撃も5秒以上ない場合、毎秒回復が発火
- **作用対象**: 勇者はHPのみ、魔王はHP・MPに作用（勇者のリソースはSPのみで、MPは魔王専用）
- **回復量**: MaxXxx × (0.005 × 1.1^step) で等比増加（ceil 切り上げ）
  - tick 0: 0.5%
  - tick 1: 0.55%
  - tick 2: 0.605%
  - ...
- **リセット条件**: 攻撃クリック / スキル発動 / 被弾で即時リセット
- BOT には適用なし

#### 死亡・リスポーン

- 死亡 → StartTown でリスポーン
- 待機時間 = 10 + (死亡回数 × 5) 秒（上限は未定）
- リスポーン中: 入力ロック、Body 非表示、カウントダウン UI 表示
- 復帰地点: リスポーン地点は常にはじまりのまちのみ。前線へ戻る手段はワープ地点設定スキルで補う

#### 落下対策

- 橋や島から落ちて深い川・海に着水すると、自動ではじまりのまちへ戻る（勇者と魔王が対象。死亡扱いにはしない）。深い川に落ちた高さの目安は y<1.5m（BalanceConfig.deepWaterFallHeight、仮）
- それ以外で Y < -10 になったときは「Backspace でリスポーン」を表示し、Backspace キーで StartTown に復帰する

### 魔王（Demon King）仕様

#### ステータス

- HP=500（撃破で勇者勝利。値は試算してから決める）、MP=200（スキル消費）、移動速度 4.5
- ピッチ/ヨー視点操作可能（マイクラ風）
- **スキル（方針）**: MPを消費して使う。具体的なスキル内容・消費MP・クールタイムは未定
  - 近接・範囲攻撃: 城内で勇者と直接戦うための攻撃スキル
  - 魔物の強化・支援: 範囲内の魔物へのバフ、回復、追加召喚など
  - 勇者への妨害・設置: スロー、落とし穴、罠などの妨害型・設置型スキル
  - 探知: MPを消費して一定時間すべての勇者を表示する（俯瞰モードの項を参照）
- **キャラ別の差別化**: 魔王キャラごとにスキル構成を変える。ここで定義するのは基本の魔王のスキルとし、後で他キャラへ拡張する

#### レベルシステム

- 100秒おきに自動レベルアップ（Lv15は23:20、Lv16は25:00に到達）
- 最大 Lv16（25:00以降の残り5分間が最終局面）
- レベル上昇による強化（方針。数値は仮）:
  - 魔物ステータス: 全魔物のHP・Atkがレベルごとに上昇（仮: Lv1基準で +5%/Lv、Lv16で +75%）
  - 魔物の解禁: 新しい魔物種がレベルで解禁される（BasicMob は初期から使用可。TankMob は Lv3、FlyingMob は Lv6 で解禁（仮値）。解禁前の魔物は準備フェーズのスポナー初期配置にも置けない）
  - コスト上限: スポナーの MaxCost がレベルごとに増加（仮: +1/Lv）
  - 魔王本体: HP・MP・攻撃力が上昇し、スキルが解放・強化される（具体値と魔王スキルは未定）
- レベルに応じて赤い空と渦雲の半径が伸びる（6段階）

#### 赤い空と渦雲

魔王城を中心に、灰色の雲が渦を巻いている。雲より上の空は赤く、外へ向かって青空へなだらかにつながる。魔王レベルの段階が上がるたびに、赤い空と雲の半径が伸びる。半径は城からまちまでの水平距離（現在約509m）に対する割合で持つので、フィールドを広げても同じ割合で届く。

| Lv | 段階 | 半径（城〜まちの距離に対する割合、仮） | 現在のステージでの半径 |
| --- | --- | --- | --- |
| 1-3 | 1 | 0.2 | 102m |
| 4-6 | 2 | 0.3 | 153m |
| 7-9 | 3 | 0.45 | 229m |
| 10-12 | 4 | 0.6 | 305m |
| 13-15 | 5 | 0.8 | 407m |
| 16 | 6 | 1.1（まちの上まで届く） | 560m |

- **広がり方**: 段階が上がると20秒（仮）かけて次の半径まで伸びる。
- **雲**: 角ばったかたまりを3本のらせんの腕に並べる（2,100個、仮）。全体がゆっくり回り（0.04rad/秒、仮）、かたまりは腕に沿って中心へ流れ込む。底の高さは65m（仮、stormCloudHeight）で、見た目だけの演出なので当たり判定はない。
- **赤い空**: 雲より上（高さ85m、仮）に広がっているように描く。地平線の近くと外側は青空のまま。
- **明るさ**: 見ている場所が嵐の下なら赤く暗い光、外なら明るい光になる。マップ全体が一度に色を変えることはない。
- **雷**: 最後の段階で、5〜12秒間隔でフラッシュする。
- **俯瞰モード**: 真上からの視点では雲を描かず、地図を隠さない。

#### 城内外挙動

- 城内（DemonCastle RegenTrigger）: MP 自動回復 +10/秒
- 城外: MP ドレイン -5/秒（Lv15 で無効化）
- 城外滞在デバフ: 城外にいる時間に応じて、移動速度と攻撃力にデバフが蓄積し、時間経過とともに強まる。城外では60秒で最大 -30% まで蓄積し、城内に戻ると同じ速さ（最大値から60秒で0）で徐々に回復する（数値は仮値。MPドレインとの併用可否は未定）
- 城内の魔王: 城内にいる間はデバフなしの最強状態を保つ
- 指揮官オーラ: 半径10m 内の魔物に Atk×1.1、Spd×1.1

#### 視点切替（俯瞰モード）

- DemonCastle_Core にタッチ → V キーで俯瞰視点へ
- **俯瞰中**:
  - マップ全体を真上から見下ろし（orthographic）
  - 勇者は原則非表示（位置不明）。ただし次の手段で把握できる
    - スポナー検知: スポナーの検知範囲（30m）に入った勇者がマップ上に表示される（HP=0 で機能停止したスポナーは検知しない）。塔は砂漠にしかないので、森と山の勇者は探知スキルでしか見えない
    - 探知スキル: 魔王がMPを消費して、一定時間すべての勇者をマップ上に表示する（仮値: 消費MP40、持続5秒、クールタイム30秒。俯瞰マップのボタンで使う）
    - 城への侵入警告: 勇者が魔王城の城内（RegenTrigger 範囲）に侵入したときに警告を出す（接近ではなく侵入を条件とする）。城内にいる間は、その勇者をマップにも表示する
  - スポナーHP・スポーン中の魔物位置確認可
  - スポナーごとに魔物を動的追加可能（コスト制限内、削除不可）
  - 移動はロック、マウスカーソル表示
- もう一度 V で TPS 復帰

#### BOT勇者（BotHero）

- 紫キャプセル、頭上に名前ラベル + HP バー
- 行き先（BOTにレベルはないので、魔王レベルで切り替える）
  - 序盤: いちばん近い魔物を探して、マップのどこへでも狩りに行く
  - 魔王Lv5（6:40、仮、BalanceConfig.botPushDkLevel）から: いちばん近い動いている塔へ向かって壊す。塔がなくなったら魔王城のコアへ向かう

- 10秒で自動リスポーン
- Tag="Player"（Monster の標的になる）
- 魔法使いの BOT は殴らず、人間と同じ炎の魔法弾を 10m（BalanceConfig.botMageAttackRange、仮値）の距離から撃つ。ダメージは mAtk、消費 SP も人間と同じ
- クラスの Df / mDf を持つ（強化スキルと状態異常のスローも人間と同じように効く）
- スキルを使う: 人間と同じ仕組みで動くので、消費SP・クールタイム・演出は人間と同じ。スキルレベルは1のまま
  - 回復と強化を先に考え、次に攻撃を考える。同じ順に撃たないよう開始位置はランダム
  - 攻撃: 交戦相手がスキルの射程に入ったら使う。Charge は通常攻撃の間合いより遠いときだけ
  - Heal / Recover: 味方または自分の HP が 60% 未満。GroupHeal: 範囲内の2人以上が 60% 未満、または自分が 40% 未満
  - Blessing: 敵と戦っている味方を優先し、いなければ戦闘中の自分
  - Guard / IronWall / ManaShield: 敵が 5m 以内で HP が 70% 未満。Taunt: 範囲内に敵が2体以上
  - Sprint: 交戦相手が 6m より遠い。Teleport: 敵が 5m 以内で HP が 30% 未満（町へ逃げる）
  - Detect と WarpPoint は使わない（印が本人の画面にしか出ない / 操作が人間前提）
  - 仮値（BalanceConfig）: 判断の間隔0.4秒、スキルの間隔2秒、SP回復1.5秒ごと（人間の自然回復と同じ割合）

#### BOT魔王（BotDemonKing）

- 青キャプセル、HP=500
- DemonCastle 内に立つだけ（攻撃なし、移動なし。現状の仕様で、強化方針は残タスクを参照）
- 撃破で勇者勝利

- 人間=勇者: シーンの DemonKing 非アクティブ、BotDemonKing が代役
- 人間=魔王: シーンの Hero 非アクティブ、4 BotHero が代役

#### 自然湧き（BiomeSpawner）

| --- | --- |
| 森 | BasicMob, TankMob |
| 山 | BasicMob, FlyingMob |
| 砂漠 | BasicMob, TankMob, FlyingMob（塔も立つ） |

- 上限: 魔物ごと・バイオームごとに MaxSpwn まで（仮: BasicMob 10 / TankMob 2 / FlyingMob 1）。倒すと SpwnCool のあと別の場所に湧き直す
- 湧く場所: バイオーム内のランダムな地点。勇者全員から35m以上（仮、biomeSpawnMinHeroDistance）、水辺から5m以上（仮）離れていて、まちの門まで歩いて行ける場所。演出は塔と同じポータル
- 将来、砂漠に強い魔物を置く予定（企画段階の希望。表を変えるだけで入れられる）

#### 橋の番人（BridgeGuardian）

- 魔王城へ渡る3本の橋の前（橋のたもとから陸側へ10m、仮）に1体ずつ立つ。うろつきも進軍もしない。倒されると戻らない（仮。未定）
- 魔王は魔王ロビー／マッチロビーの「橋の番人」の欄で、橋ごとの番人を選ぶ。候補は MonsterData.isBridgeGuardian の魔物で、今はゴーレムだけ。デッキとは別枠でコストはかからない。設定しなければゴーレムが立つ（BOT魔王でも同じ）

| 魔物 | HP | Atk | Df | mDf | Spd | Exp | 体の高さ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ゴーレム（すべて仮） | 1200 | 30 | 15 | 5 | 4.5 | 400 | 5m |

- **行動**: 半径30m に勇者が来ると「！」を出して追う。持ち場から45m より遠い勇者はあきらめて持ち場に戻る。触れただけではダメージなし。のけぞり・ノックバックは無効（スタンは効く）
- **叩きつけ**: 11m 以内で始める
  1. 振りかぶり 1.2秒: 両手を組んで頭上へ。最初の75%は相手の方へ向き直り、そのあとは向きが固定される（横へよければ当たらない）
  2. 振り下ろし 0.2秒: 前方2.6m の地面へ
  3. 小さな衝撃波: 半径4m、Atk の50%
  4. 岩の槍: 着地点から前へ1.7m おきに7回、0.06秒ずつ遅れて地面から飛び出す（約12m）。高さ3.4m で、0.45秒後に沈む。各所の半径1.6m に Atk の100%。1回の叩きつけで同じ勇者には1度だけ当たる（衝撃波と槍の両方は当たらない）
  5. 硬直 1.3秒、次の攻撃まで 1.5秒
- 数値はすべて MonsterData の仮値。槍の見た目は角ばった岩に紫の結晶の先端（ゴーレムの結晶に合わせる）

#### AI 挙動

- **うろつき**: 最終フェーズ（魔王Lv16、25:00）までは、まちへ向かわず、湧いた場所の周り（半径18m、仮）を歩いては止まる（1〜3.5秒、仮）
- **発見**: 半径20m 以内で、正面180度の視野（仮、monsterSightDegrees）に勇者が入ると、頭の上に黄色い「！」を出して追いかける。視野の外からでも攻撃されたら気づく。30m 離れると元に戻る
- **最終フェーズ**: 魔王Lv16になると、すべての魔物がはじまりのまちへ向かう

- **経路追従**: 最終フェーズに塔の魔物はウェイポイント（StageMap.json）に沿って、自然湧きの魔物はまっすぐ NavMesh でまちへ進む
- **ターゲット選択**: 基本は視野内（20m）で最も近い勇者を追う。ヘイト値による標的の変化は一部の賢い魔物（MonsterData の useHate）だけが持つ。現在の3種類はいずれも持たない
- **ヘイト値**: 賢い魔物は範囲内でヘイト最大の勇者を追い、全員0なら最も近い勇者を追う。今の標的のヘイトを1.1倍（仮）超えたら標的が変わる。増える条件: その魔物に与えたダメージ1につき+1、魔物の近く（仮20m）で味方を回復すると回復量×0.5（仮）。減る条件: 毎秒10%（仮）ずつ減る。死亡または20m（仮）より離れるとその勇者のヘイトは0
- **Taunt**: 範囲内の魔物にヘイト+100（仮）を加算する。ヘイトを持たない普通の魔物には効果なし
- **接触ダメージ**: 同じ魔物から 1秒に1回のみ。当たるたびに攻撃アニメーションを再生する
- **見た目（MonsterData.modelPath）**: 指定があれば Knight スケルトンのモデルを表示し、走り・攻撃は勇者と共通のクリップ（仮）を使う。未指定なら prefab の Body のまま。現在は BasicMob のみゴブリン（Goblin/goblin、modelScale 0.8 は仮。右手に短剣、左手に木の盾）で、TankMob / FlyingMob は未差し替え
- **魔物の死亡演出**: モデルのある魔物はHP0で、攻撃と反対の斜め上へぶっ飛びながら白く染まり、不規則に膨らんで白い粒に破裂する（0.75秒、発射速度11m/s、粒50個、いずれも仮値。MonsterData）。経験値はHP0の瞬間に入り、金色の粒は破裂した地点から飛ぶ。飛んでいる間は攻撃せず、攻撃も受けない。モデルのない魔物はHP0で即座に消える
- **魔物の被弾の反応**: 攻撃を受けるたびに、ダメージに比例した小さなノックバックと極小のけぞりが入る。継続ダメージでは起きない。のけぞりは状態異常のスタンとは別物で、スタン耐性を作らない。効きやすさは MonsterData.hitReactionScale（0で無効）。仮値: ノックバック 1ダメージあたり0.03m・最大1.2m / のけぞり 1ダメージあたり0.006秒・最大0.25秒（BalanceConfig）/ TankMob は無効
- **StartTown 到達時の挙動**: `agent.isStopped=true` で停止。Destroy せず、接触ダメージで継続的にコアを削る
- **指揮官オーラ被付与**: 魔王半径10m 内で強化
- **FlyingMob ContactDamage 範囲**: 地上のコアに届くよう 6m に拡大（通常半径 1.5m）

### スポナー（Spawner）仕様

#### BasicSpawner

- HP=300, Atk=15, Cool=2（自動射撃間隔）
- Exp=100, MaxCost=10, Inv=3
- AttackRange=40, DetectRange=30
- MaxConcurrent=2（SpawnInterval は廃止し、湧き間隔は魔物ごとの SpwnCool に統一）

#### 機能

- inv の魔物を順に、魔物ごとの SpwnCool に従って湧かせる
- 半径30m 内の Hero を検知して 2秒間隔で射撃。見た目はてっぺんに水晶のある塔（高さ8m、仮）で、撃つ前に水晶が光りながら0.75秒（仮、SpawnerData.attackChargeSeconds）溜め、どす暗い紫の芯にピンクの炎をまとったレーザーを放つ（魔法攻撃で mDf が効く）。溜めの時間は2秒の間隔に含み、溜め始めに一番近かった勇者がいた場所へ撃つ（動いて避けられる。誰もいなくなっても撃つ）。レーザーの線上にいる勇者に当たる。自分の塔と魔物はレーザーをさえぎらない
- 破壊された塔は黒ずみ、水晶の光が消える
- 同時生存上限 2体
- 出現演出: 警告の円（外周から内側へ薄れるグラデーションの円。1.2秒）→ 闇のポータルが開く（0.9秒）→ 魔物がポータルの下から這い上がり、炎と煙の中から飛び出す（1.1秒）→ ポータルが閉じる。秒数と半径（1.4m）は仮値で BalanceConfig に置く
- 魔物の生成はポータルが開いた瞬間で、這い出している間は動かず、攻撃せず、攻撃も受けない（無敵）。SpwnCool は警告の円が出た時点から数え、演出中の魔物も同時生存上限に含める。スポナーが破壊されると、まだ魔物が出ていないポータルは閉じて取り消す
- HP=0 で機能停止（湧き・射撃停止、グレー化、残骸として残る）。復活・修復はしない（ワープ地点を設定できる範囲の基準にもなる）
- 試合中に魔王が動的に魔物追加可能（俯瞰モード経由）

### マップ構成（MainStage）

- **ステージ規模**: 500m 四方（仮）。データの正は Resources/StageMap.json で、Blender の地形作成（ArtSource/lowpoly/build_lowpoly.py）とゲーム（StageMap.cs）の両方がこれを読む
- **バイオーム**:
  - はじまりのまち: 左上 (-172, 193)
  - 山脈（右上）: 中央に大きな山 (165, 178) と小さな山々。起伏のある山道 (road mountain) を歩く。登りで足が遅くなるので重戦士は動きにくく、木がないので魔法は当てやすい
  - 砂漠（中央）: 平らで見通しがよい。塔5本と自然湧きの魔物がいる。将来、強い魔物を置く予定
  - 森（左下）: 木が約540本（間隔5.5m）。幹に当たり判定があり魔法の弾や視線をさえぎる（15mの線の26%が遮られる。草原は2%）。平らなので重戦士や近接が動きやすい
- **道**: まちの門 (-145, 165) から山・砂漠・森それぞれを通って橋まで3本
- **川**:
  - 浅瀬の川（幅16m）: 歩いて渡れる。速度×0.925（仮、shallowSpeedMultiplier）。歩くと波紋が出る
  - 深い川（幅26m）: 2本。砂漠の両脇を流れる。見えない壁があり渡れない
  - 海: 右下の角一帯。岸に見えない壁があり、橋の入口だけ開いている
- **魔王城の島**: 海の上空に浮かぶ（高さ30m、半径46m、中心 (167, -187)、いずれも仮）
- **吊り橋**: 山・砂漠・森それぞれの岸から1本ずつ、計3本（幅8m、長さ103〜135m）。岸から垂れ下がる曲線で登り、島の縁で傾き20度（仮）になる。手すりは腰の高さのロープで当たり判定がなく、踏み外すと海へ落ちてまちへ戻る。両岸に門柱を立て、主ロープと吊りロープで踏み板を吊る。揺れはしない。魔物と BOT は NavMesh で渡れる。橋の手前にゴーレムが立つ
- **地形の性質（登り）**: 30度の登りで足が遅くなる割合（HeroClassData.slopeSpeedPenalty、仮）: 重戦士45% / 剣士20% / 魔法使い・僧侶15% / 魔王25%（demonKingSlopePenalty）。下りと平地は変わらない。TerrainWalker が勇者・BOT・魔王・魔物の速度に掛ける
- **作り直す手順**: StageMap.json か build_lowpoly.py を変えたら、Blender で LP_Field.fbx を書き出し → MainStage で Tools/LowPoly/Apply Stage Layout And Rebake NavMesh → シーン保存 → Title シーンで Tools/LowPoly/Bake Dig Data
- **地面を削る仕組み**: 地面だけを実際に削れるようにする（壁や建物は壊さない）。普段の地面の見た目は今のローポリのままで、削れた場所だけ切り抜いて土の面を見せる。ブロックの断面は見せない。
  - 見た目: フィールドそのものが削れて見えるようにする。立方体は使わず、格子の頂点を少しずらして三角形でつないだ、角ばった面で作る。滑らかにはせず、周りの低ポリに合わせた紙細工のような質感にする。参考: 『ドンキーコング バナンザ』のボクセル（格子の頂点からメッシュを作り、角を立てて形を見せる）。
  - 形: 段々のすり鉢状で、段の間は急な坂。輪郭はいびつな多角形。歩いてそのまま出られる。足場と坂で色を変え、深いほど湿って暗い土にする。穴のすぐ外も草がはがれて土が見える。
  - 削れるスキル: Stomp と Explosion のみ。削った跡は試合中戻らない。重ねて削ると深くなる（最大深さまで）。
  - 削れない場所: はじまりのまち、魔王城、スポナーの周り、木の周り、岩・壁・塔の周り、フィールドの外周。
  - 草は削れた部分だけ消える。NavMesh は作り直さず、魔物と BOT は足元の深さに合わせて体を上下させる（経路は変わらない）。
  - ネットワークでは「どこを、どの範囲、どの深さまで」だけ同期する。形はこの値だけで決まるので、どの端末でも同じ穴になる。
  - 仮値: 格子 0.75m / 1段 0.25m / 最大深さ 1m / Stomp 半径3m・深さ0.5m / Explosion 半径8m・深さ1m（どちらもスキルの大きさに合わせて広がる）/ 削れない幅: 岩・壁・建物・塔 1.5m、スポナー 4m、木 2m、外周 3m。BalanceConfig と SkillData に置く。
  - 木の位置は `Tools/LowPoly/Bake Dig Data` で GroundDigData に保存している。フィールドのモデルを作り直したら実行し直す。

### UIデザインの方針

2026-11-06 にHUDのデザイン案（試合中HUDデザイン案。勇者の通常・戦闘中・スキルホイール、魔王の行動中・俯瞰、部品と色）で方向を決めた。

- **参考にしたもの**: 画面の構成は Dead by Daylight、見た目は A Hat in Time。魔王側の暗い色は Cult of the Lamb、魔王の俯瞰と編成の画面は Evil Genius 2。ほかの作品を参考にするときは、作品ごとに相談してから使う
- **見た目**: 布（フェルト）と紙の手作り風。縫い目の点線、やぶれた紙、リボン、マスキングテープ、白い縁のシール。勇者側は紫のフェルトとクリーム色の紙、魔王側は同じ作りを黒・暗い赤・骨色にする
- **配置（試合中）**:
  - 上中央: 残り時間の丸い時計。左に「はじまりのまち」、右に「魔王城コア」のHP。時計の下のリボンに、勇者側は魔王のLv、魔王側は次のLvまでの時間を出す。勇者側はコアの下に魔王のHPも出す
  - 右上: いる場所（はじまりのまち・砂漠・森・山・川・海・魔王城など）
  - 左下: 自分（大きな丸い肖像、Lv、HP・SP・Exp）。その上に味方3人（肖像・名前・HP）と、かかっている状態異常（名前と残り秒）
  - 右下: スキルカード5枚。キー番号、Lv、イラスト、名前、消費SP。選択中は浮き上がって金の縁。クールダウン中は幕と残り秒、SP不足はイラストを灰色にして消費SPを赤くする。選択中のスキルで減るSPはSPバーに斜線で示す
  - 中央下: その場で必要な案内だけ
- **色**: HP #ef5a55 / SP #f5b829 / Exp #76dcb8 / MP #a98bff / はじまりのまち #2aa893 / 魔王城コア #9a45d6。勇者のフェルト #3a2a5e、紙 #f7e9c8、リボン #c9303a。魔王のフェルト #1b1116、紙 #eadfc8、リボン #8e1b22
- **文字**: 見出しと数字は Mochiy Pop One（仮決め。候補は Dela Gothic One / RocknRoll One / Potta One。どれも Google Fonts で商用利用可）
- **スキル名**: 画面では日本語の表示名（SkillData.displayName）を出す（仮決め）。skillName は処理の判定に使っているので英語のまま
- **作り**: 部品はコードで組み立てる（Scripts/UI/Hud。HudStyle に色・文字・部品、HudShape が角丸・円・リボン・やぶれた紙、HudStitch が縫い目、ThickOutline が文字の太い縁取り、HudBar がバー）。専用の HudCanvas（sortingOrder -1）に置き、リスポーンやリザルトなどほかのUIより奥に描く。布と紙の模様は ArtSource/ui/build_hud_textures.py で作る Resources/UI/HudFelt.png と HudPaper.png、文字は Resources/Fonts/MochiyPopOne-Regular.ttf

### 操作（キーバインド）

デバッグ機能はすべてコマンド経由に統一されたため、以下のキーは実機能またはコマンド入力トリガーとしてのみ維持される。
