## 1. ゲームの全体像

### (1) ゲームの基本コンセプト

非対称マルチプレイの3Dアクションストラテジー。5人（勇者4人 + 魔王1人。勇者が4人に満たない場合は不足分をBOT勇者で補う）で30分の試合を行う。

ゲームのイメージ: 第五人格/Dead by Daylight × League of Legends/ポケモンユナイト

### (2) 試合のシチュエーション

勇者チームはマップ左上の「はじまりのまち」からスタートし、マップ右下の空に浮かぶ魔王の城を目指す。森・山・砂漠には魔物が自然に湧き、砂漠には魔王の塔（スポナー）が立つ。魔物は最終フェーズ（魔王Lv16）になると、勇者のまちを破壊しに向かう。両陣営は同じマップで戦う非対称対戦方式を採用している。

### (3) 勇者チームの目的と行動

- **目的**: 魔王城の中心にあるコアを破壊するか、魔王本体を倒すこと
- **行動**:
  - ジョブ（剣士/魔法使い/僧侶/重戦士）を選んでスキルセットを構築
  - はじまりのまちからマップ中央〜魔王城方向へ進軍
  - 道中の魔物を倒して経験値を稼ぎ、スキルをレベルアップ
  - 砂漠の塔（スポナー）を破壊して、塔からの魔物の湧きを止める（森・山・砂漠の自然湧きは止まらない。大経験値も得られる。序盤の目標として、破壊時にボーナスを付けて誘導する。ボーナスの内容は未定）
  - 仲間と連携して魔王城に攻め込む
- **勝利条件**: 以下のいずれかを達成
  - 魔王城コアの HP を 0 にする
  - 魔王本体の HP を 0 にする
- **設計方針**: 魔王は城内で最強のため、魔王が城外に出続けている場合を除き、勇者は城内で魔王と戦うかコアを破壊するかのどちらかを行う。勇者が成長しないと勝てない設計とし、開始直後の速攻勝利が起きないようにする（魔王のHP・城内の防衛手段の具体値は未定）

### (4) 魔王チームの目的と行動

- **目的**: 勇者の拠点「はじまりのまち」のコアを破壊すること
- **行動**:
  - 試合前に魔王ロビーの地図で、山・森・砂漠それぞれに通常魔物（3枠）と中ボスを置き、3本の橋に番人（ゴーレム）を置く。フィールド魔法を6種から5つ装備する（2026-11-08。魔物は最終的に20種類用意する）
  - 試合開始前の1分間で5箇所のスポナーに魔物を割り当て
  - 試合中は魔王城のコアに触れることで俯瞰モードに移行し、戦況を見ながらスポナーに魔物を追加（コスト制限内、削除不可）
  - 城外にも出て直接戦闘に参加可能（MPドレインと、移動速度・攻撃力のデバフのリスクあり）
  - 試合中は装備したフィールド魔法（竜巻・雷・地震・隕石・魔力暴発・豪雨）を 1〜5 キーで使う。TPS でも俯瞰でも使え、使うのはクールタイムだけ
  - 100秒ごとにレベルアップ（最大Lv16、試合開始25:00に到達）、城を中心にした赤い空と渦雲が広がっていく
- **勝利条件**: はじまりのまちのコアの HP を 0 にする

### (5) 試合フロー

タイトル画面 → ロビー（勇者ロビー or 魔王ロビー） → マッチング → マッチロビー（1分準備） → 試合（最大30分） → リザルト → タイトルに戻る

- **ジョブの見た目**: 全ジョブとも外部で作ったテクスチャ付きモデルに差し替え済み。持ち物は、剣士が右手の剣と左手の盾、魔法使いが右手の杖と左手のそばに浮かぶ本（FloatingHeldItem）、僧侶が右手の杖と左手の本、重戦士が右手の斧と左手の盾。魔王も外部で作ったモデル（王冠と長いローブ・マントの吸血鬼風。Resources/DemonKing/demon_king.fbx）で、右手に紫の結晶の剣を持つ。マントの背中側は腕に付けず胴について行く。見た目の大きさは 魔王 ＞ 重戦士 ＞ 剣士 ＞ 魔法使い ＝ 僧侶 ＞ ゴブリン（倍率の仮値は 魔王1.5 / 重戦士1.15 / 剣士1.05 / 魔法使い0.93 / 僧侶0.89 / ゴブリン0.70。HeroClassData.modelScale、MonsterData.modelScale、BalanceConfig.demonKingModelScale）。当たり判定の大きさは見た目に連動させず、共通のまま。どのモデルも Knight の骨格とアニメーションを共有し、関節の位置だけモデルごとに合わせる（ModelBoneFit）。作り方は ArtSource/characters/rig_tripo.py

- **成長値（レベル毎）**: ジョブごとに異なる成長値に統一する（剣士は HP+12, Atk+2 など。全ジョブの成長値の数値表は未作成）
- **防御の種類**: 物理防御（Df）と魔法防御（mDf）に分ける。物理攻撃（Atk系）にDf、魔法攻撃（mAtk系）にmDfを適用する。mDfはジョブの性格でDfと逆転させ、魔法使い・僧侶は魔法に強く、重戦士は魔法に弱い（魔物・魔王のmDfは未定）
- **ダメージ計算式**: ダメージ = 攻撃値 × K / (K + 防御値)。攻撃値は Atk（物理）または mAtk（魔法）、防御値は Df または mDf。K は調整定数（仮: K=20。スキル倍率・最低ダメージ・クリティカルの有無は未定）
- **通常攻撃（左クリック）**: ジョブごとに次の仕様（射程・攻撃間隔の数値は未定）
  - 剣士: 近接単体攻撃（Atk）
  - 重戦士: 近接の大振り。近距離の範囲攻撃（Atk）
  - 魔法使い: 遠距離の魔法弾（mAtk）。白い芯・マゼンタ・青・紺が重なる涙滴形の炎で、丸い根元を先頭に尾をうねらせて飛ぶ（短い紺色の軌跡と粒も残す）。杖の宝石のあたりから照準点へ飛び、壁や地面に当たると消える。射程28m（仮、BalanceConfig.mageBoltRange）で、塔が勇者を撃つ範囲（検知範囲30m）より少し短くし、塔の外から一方的に塔を撃てないようにする。BOT の魔法使いは10mまで近づいてから撃つ（botMageAttackRange）
  - 僧侶: 中距離の光弾（mAtk、威力は控えめ）

#### スキル（5スロット）

- スロット 1〜4: 選んだジョブのスキルか共通スキルから4つ（ロビーで入れ替えられる。標準はジョブのスキルの先頭4つ。2026-11-07 にユーザーが決定）
- 消費リソース: 勇者のリソースは MP（2026-11-07 に SP から MP へ戻した）。MP を使うのは魔法系のスキルだけで、魔法使い・僧侶のスキル、共通スキル（探知・自己回復・疾走・帰還）、魔法使いの通常攻撃とダブルジャンプが対象。剣士・重戦士のスキルと剣士の斬撃パッシブは物理系なので MP を使わず、クールタイムが終わっていればいつでも使える（SkillData.mpCost = 0）。最大MPは 魔法使い・僧侶が多く、剣士は普通、重戦士は少なめ（仮値: 魔法使い70・僧侶70・剣士40・重戦士25、Lvごとに +7 / +7 / +4 / +2）。物理系スキルのクールタイムは消費MPをなくした後も据え置く（2026-11-07 にユーザーが決定）
- スロット 5: 自由枠。ジョブに関係なくどのスキルでも入る（ほかのジョブのスキル、自分のジョブのスキル、共通スキル）。パーティ内で同じスキルを複数人が選ぶことはできない（未実装）。ジョブの重複は可
  - 同じスキルを2つの枠に入れることはできない。ほかのジョブのスキルは5枠目にだけ入る
  - ジョブのスキルは HeroClassData.classSkills（先頭4つが標準）と extraClassSkills（標準に入らない追加のスキル。いまは魔法使いの Explosion だけ）。魔法使いは 火球・吹雪・ワープ・魔力の盾・爆発 の5つから選ぶ（2026-11-07 に瞬間移動が共通スキル「帰還」になり、代わりにワープが入った）
  - ロビーで選んだ1〜4枠は GameSession.SelectedClassSkills、5枠目は SelectedCommonSkill に入り、試合では HeroClassInitializer.ClassSkills → SkillRuntime が装備する。BOT はジョブの標準4つ
- **ワープ（魔法使いのスキル、WarpPoint）**: 2026-11-07 に共通スキルの「ワープ地点設定」から魔法使いのスキルに変えた。1回目で目の前（仮 2.5m）に門を1つ開く（MP・クールタイムなし）。別の場所で2回目を使うと、もう1つ門を開いて2つをつなぐ（ここで消費MP 20・クールタイム45秒、仮）。2つの門は仮 10m 以上離す必要がある。つながる前の門は60秒（仮）、つながった門は30秒（仮）で閉じる。新しくつなぐと前の2つは閉じる。死んでも門は残る
  - 門の中には反対側の門の向こうの景色が見える（反対側の門の向こう側に置いたカメラで描いた絵を映す）。つながる前は星の空
  - 形と色は参考動画（泡がくっついて開く門）に合わせた: いくつもの泡がくっついた形で、小さな泡がまわりを漂い、縁はピンク→紫→水色→緑→黄のネオンに光る。開くときは小さな泡が育ってくっつく（0.8秒、仮）

  - 置ける場所の制限はなくした（以前の「破壊済みスポナーより自陣側」はなし。必要なら決め直す）
  - BOT は使わない

- **スキル演出の共通方針**: 発動は「短い溜め（最長1秒）→ 発動 → 余韻」の流れで、大きい技ほど派手にする。ジョブごとに色を決める（剣士は白銀と青）。MP とクールタイムは発動の瞬間に消費し、溜め中のスタン・沈黙・死亡で中断されたら消費しない。溜め中は他のスキルと通常攻撃を使えない。溜めの秒数は SkillData.castTime に置く。
- **1人称の腕と武器**: 自分の視点には、ジョブのモデルから取り出した腕と武器を表示する（全ジョブ共通の仕組み）。壁にめり込まないよう、最後に重ねて描く。構えの位置は HeroClassData に置く（重戦士の斧は視界をふさがないよう、2026-11-07 に少し右へ倒して右に寄せた: viewRightEuler (30, -15, -34)、viewRightPosition (0.23, -0.16, 0.42)）。他のプレイヤーからは、今のアニメーションクリップとコードでの姿勢変更で動いて見える。
- **速さの手応え**（2026-11-07）: 走るほど視野角が少し広がり（最大 +2度）、ダッシュ中は +9度まで広がって、画面の外側に白い集中線が流れる（いずれも仮値、BalanceConfig の runFovBoost / dashFovBoost / speedFovSmoothing / dashSpeedLines）。スキルの視野角の演出とは足し合わせる（視野角は HeroFPSController がまとめて持つ）
- **被弾の手応え**（2026-11-07）: 魔物・ボス・魔王から攻撃を受けると、相手と反対へごくわずかに押され（0.35m を0.15秒、仮、heroHitKnockback）、画面が少し揺れ（heroHitShake 0.04、仮）、左下の自分の HP バーが横に小刻みに揺れる（0.35秒・9px）。味方からと継続ダメージでは押されない
- **歩き・走りの揺れ**: カメラと腕は一歩ごとに縦に少し沈むだけで、左右の揺れと傾き（回転）はつけない（2026-11-07 に変更）。歩幅は3.2m、ダッシュは4.4m（HeroFPSController。秒速10m で1秒に約3回）。沈む深さは3.5cm、ダッシュは1.3倍
- **Slash（剣士）**: 前方の扇形にいる敵すべてに当たる（以前の「視線の先の1体」は廃止）。三日月形の斬撃が走り、当たると火花とヒットストップが入る。壁の向こうには当たらない。味方は巻き込まない。
  - 仮値: 溜め0.2秒（移動可）/ 射程3m / 扇の角度120度（SkillData.coneAngle）
- **Charge（剣士）**: 溜めのあと、向いている方向へ実際に突進する（以前は移動しなかった）。最初にぶつかった敵1体に当たり、衝撃の輪と閃光とともに止まる。誰にも当たらなければ射程の分だけ進んで止まる。壁に当たっても止まる。
  - 仮値: 溜め0.4秒（移動不可）/ 突進距離6m（range）/ 突進の速さ24m/s（SkillData.dashSpeed）
- **Whirlwind（剣士）**: 溜めのあと体ごと2回転し、周囲の敵すべてに1回ずつ当たる。円形の斬撃と衝撃の輪が広がる。
  - 仮値: 溜め0.5秒（移動不可）/ 半径5m（range）
- **Guard（剣士）**: 盾を構え、光の膜をまとう。効果中は攻撃を受けるたびに膜が光る。効果中も移動と攻撃はできる。
  - 仮値: 溜め0.15秒（移動可）/ Df 1.5倍 5秒は変更なし
- **Bash（重戦士）**: 溜めのあと盾を前に構えて前方へ高速で突っ込む。ぶつかっても止まらず進み、触れた魔王・魔物すべてに1回ずつ中ダメージを与えて、前へ大きく突き飛ばす（以前のスタン1秒は廃止）。壁や押せない敵にぶつかると止まる。押し飛ばしは MonsterData.hitReactionScale の影響を受け、0 の敵には効かない。コアとスポナーは動かない。
  - 仮値: 溜め0.25秒（移動不可）/ 突進距離8m（range）/ 突進の速さ22m/s（dashSpeed）/ 突き飛ばす距離9m（knockbackDistance）/ ダメージ35 / 消費MPなし / クールタイム6秒（以前は3秒。移動技になったため仮で延長）
- **Stomp（重戦士）**: 溜めのあと、通常ジャンプより高く跳んで斧を振り上げ、勢いよく急降下する。着地点の真下の敵には大ダメージ、周囲の敵には衝撃波で中ダメージ。直撃でも衝撃波でも、当たると低確率で3秒スタンする（以前のスロー-40% 2秒は廃止）。着地で衝撃の輪・閃光・土煙が広がり、着地点の地面が削れて、角ばった土のかけらが飛ぶ（削れない場所では代わりに赤熱したヒビが走り、冷めたあとしばらく残る）。
  - 仮値: 溜め0.2秒（移動不可）/ 跳ぶ高さ2.8m（leapHeight。通常ジャンプは約0.6m）/ 急降下24m/s（diveSpeed）/ 前への移動2m / 直撃の半径1.5m・ダメージ2倍の60（directHitMultiplier）/ 衝撃波の半径5m（range）・ダメージ30 / スタン確率15%（statusChance）/ ヒビが残る時間6秒+消えるまで1.6秒 / 消費MPなし・クールタイム8秒は変更なし
- **Taunt（重戦士）**: 溜めのあと斧を掲げて身を反らし、前に踏み込んで吠える。周囲へ赤い衝撃の輪が広がる。効果は変更なし（賢い魔物のヘイトを上げる）。仮値: 溜め0.3秒（移動不可）
- **IronWall（重戦士）**: 動きは Guard と同じで、盾を構えて琥珀色の光の膜をまとう。効果は変更なし（Df 2倍 6秒）。仮値: 溜め0.15秒（移動可）
- 重戦士の演出の色は琥珀と赤熱（MeleeFx.Ember）。
- **Heal（僧侶）**: 溜めのあと杖を掲げ、照準の先の味方へ光を送る。相手の足元から光の柱が立つ。照準の先に味方がいなければ（敵や壁を狙っていても）自分を回復する。敵は回復しない。
  - 仮値: 溜め0.25秒（移動可）/ 射程8m（狙いの太さ半径0.5m）。回復量30・消費MP15・クールタイム2秒は変更なし
- **GroupHeal（僧侶）**: 溜めのあと足元から金色の輪を広げ、範囲内の味方全員（自分を含む）を回復する。回復した全員の足元に光の柱が立つ。敵は回復しない。

#### HP/MP 自動回復システム

- **勇者の MP の回復**: 勇者の MP は主に次の2つで回復する。自然回復はごく少量（魔王の MP は別の仕組み）
  - **魔物に通常攻撃を当てる**: 当たるたびに最大MPの6%（仮、BalanceConfig.mpPerBasicHit）。スキルの命中、魔王や塔への攻撃では回復しない
  - **はじまりのまちに戻る**: まちの中心から半径26m（仮、townRefillRadius）に入ると全回復
  - **自然回復**: 1.5秒ごとに最大MPの一定割合。1未満の端数はためておき、1になったら回復する（ManaComponent.RestoreFraction）。割合は HeroClassData.mpCombatRegenRate（仮: 剣士・重戦士 0.25%、魔法使い・僧侶 0.4%）
- **発火条件（増えていく回復）**: 攻撃も被攻撃も5秒以上ない場合、毎秒回復が発火
- **作用対象**: 勇者はHPのみ、魔王はHP・MPに作用（勇者の MP は上の「勇者の MP の回復」だけで回復する）
- **回復量**: MaxXxx × (0.005 × 1.1^step) で等比増加（ceil 切り上げ）
  - tick 0: 0.5%
  - tick 1: 0.55%
  - tick 2: 0.605%
  - ...
- **リセット条件**: 攻撃クリック / スキル発動 / 被弾で即時リセット
- BOT には適用なし

#### 死亡・リスポーン

- 死亡 → StartTown でリスポーン
- 待機時間 = 10 + (死亡回数 × 5) 秒（上限は未定）
- リスポーン中: 入力ロック、Body 非表示、カウントダウン UI 表示（画面の真ん中をふさがないように少し上に出す）
- 死んでいるあいだの視点（HeroDeathCamera）: 1人称のままにせず、目の高さから1.2秒（仮）で上へ引いて、倒れる自分を斜め上（高さ6m・後ろ7m、仮）から見下ろす。ゆっくり回る（毎秒8度、仮）。照準は消す。数値は BalanceConfig の Death Camera
- リスポーンのアニメーション（4秒）のあいだも外からの視点: まちに戻った自分を斜め上（高さ3.5m・距離5.5m、仮）から映し、前（150度、仮）から背中側へ回り込む。右回りと左回りのうち建物にさえぎられにくい方を選び、さえぎられたら近づかずに高く上がって見通す。最後の0.6秒（仮）で目の高さへすっと戻って1人称になる。外から映しているあいだは自分の頭上の HP バーを隠す
- 復帰地点: リスポーン地点は常にはじまりのまちのみ。前線へ戻る手段は魔法使いのワープの門と、共通スキルの帰還（まちへ戻るだけ）

#### 落下対策

- 勇者が橋や島から落ちて深い川・海に着水するか、Y < -10 まで落ちたら（奈落）、倒れたのと同じ扱いになる（2026-11-07 に変更）。死んでからリスポーンまでの待ち時間・上からの視点・死亡回数もふつうの死亡と同じ。深い川に落ちた高さの目安は y<1.5m（BalanceConfig.deepWaterFallHeight、仮）
- 魔王は今までどおり、深い川・海に落ちると魔王城へ戻り、Y < -10 では「Backspace でリスポーン」を表示する（魔王の落下を死亡扱いにするかは未定）
- **海にはどこからも入れない**（2026-11-08）: 海岸・深い川の両岸と端・橋の両側・浮島の縁に見えない壁がある。浅瀬の川を歩いて深い川や海の方へ進んでも、深い川の端の壁で止まる（深い川の水の範囲は端を丸めず平らに切る。以前は端の丸い部分が浅瀬の中まで深い水になっていて、浅瀬から入ると死んでいた）
- それでも侵入不可エリア（深い川・海・奈落）に入ってしまったときは、リスポーン待ちの表示が「あなたは倒された」ではなく「侵入不可エリアに入ったため、まちへ戻ります」になる（RespawnManager.SetDeathReason）

  - 近接・範囲攻撃: 城内で勇者と直接戦うための攻撃スキル

#### 赤い空と渦雲

魔王城を中心に、灰色の雲が渦を巻いている。雲より上の空は赤く、外へ向かって青空へなだらかにつながる。魔王レベルの段階が上がるたびに、赤い空と雲の半径が伸びる。半径は城からまちまでの水平距離（現在約509m）に対する割合で持つので、フィールドを広げても同じ割合で届く。

| Lv | 段階 | 半径（城〜まちの距離に対する割合、仮） | 現在のステージでの半径 |
| --- | --- | --- | --- |
| 1-3 | 1 | 0.2 | 102m |
| 4-6 | 2 | 0.3 | 153m |
| 7-9 | 3 | 0.45 | 229m |
| 10-12 | 4 | 0.6 | 305m |
| 13-15 | 5 | 0.8 | 407m |

- **広がり方**: 段階が上がると20秒（仮）かけて次の半径まで伸びる。
- **雲**: 角ばったかたまりを3本のらせんの腕に並べる（2,100個、仮）。全体がゆっくり回り（0.04rad/秒、仮）、かたまりは腕に沿って中心へ流れ込む。底の高さは65m（仮、stormCloudHeight）で、見た目だけの演出なので当たり判定はない。
- **赤い空**: 雲より上（高さ85m、仮）に広がっているように描く。地平線の近くと外側は青空のまま。
- **明るさ**: 見ている場所が嵐の下なら赤く暗い光、外なら明るい光になる。マップ全体が一度に色を変えることはない。
- **雷**: 最後の段階で、5〜12秒間隔でフラッシュする。
- **俯瞰モード**: 真上からの視点では雲を描かず、地図を隠さない。

#### BOT勇者（BotHero）

- 紫キャプセル、頭上に名前ラベル + HP バー
- 行き先（BOTにレベルはないので、魔王レベルで切り替える）
  - 序盤: いちばん近い魔物を探して、マップのどこへでも狩りに行く
  - 魔王Lv5（6:40、仮、BalanceConfig.botPushDkLevel）から: いちばん近い動いている塔へ向かって壊す。塔がなくなったら魔王城のコアへ向かう
  - 半径24m 内に魔物がいれば先に戦う。攻撃範囲3m（塔とコアは表面までの距離で測る）
  - HPが30%未満でまちへ戻り、80%以上で再び出発する（仮、botRetreatHpRatio / botReturnHpRatio）。行き先の見直しは2秒ごと（仮、botGoalInterval）
- attackInterval=1.5 秒、damage=classData.initialAtk
- 10秒で自動リスポーン
- Tag="Player"（Monster の標的になる）
- 魔法使いの BOT は殴らず、人間と同じ炎の魔法弾を 10m（BalanceConfig.botMageAttackRange、仮値）の距離から撃つ。ダメージは mAtk、消費 MP も人間と同じ
- ジョブの Df / mDf を持つ（強化スキルと状態異常のスローも人間と同じように効く）
- スキルを使う: 人間と同じ仕組みで動くので、消費MP・クールタイム・演出は人間と同じ。スキルレベルは1のまま
  - 回復と強化を先に考え、次に攻撃を考える。同じ順に撃たないよう開始位置はランダム
  - 攻撃: 交戦相手がスキルの射程に入ったら使う。Charge は通常攻撃の間合いより遠いときだけ
  - Heal / Recover: 味方または自分の HP が 60% 未満。GroupHeal: 範囲内の2人以上が 60% 未満、または自分が 40% 未満
  - Blessing: 敵と戦っている味方を優先し、いなければ戦闘中の自分
  - Guard / IronWall / ManaShield: 敵が 5m 以内で HP が 70% 未満。Taunt: 範囲内に敵が2体以上
  - Sprint: 交戦相手が 6m より遠い。Teleport: 敵が 5m 以内で HP が 30% 未満（町へ逃げる）
  - Detect と WarpPoint は使わない（印が本人の画面にしか出ない / 操作が人間前提）
  - 仮値（BalanceConfig）: 判断の間隔0.4秒、スキルの間隔2秒、MP回復1.5秒ごと（人間の自然回復と同じ割合）

#### 新しい雑魚魔物の動きと技（2026-11-08）

- **共通**: 外部で作ったモデル（Tripo）に、それぞれ専用の骨を入れた（ArtSource/characters/build_monsters.py。Resources/<Dryad|Mummy|Ifrit|Harpy|Cockatrice>/）。騎士のクリップは使わず、MonsterBehaviour の派生（DryadBehaviour ほか）が骨をコードで回す（MonsterData.customRig / kind）。勇者に触れただけではダメージを与えない（技だけ。まちのコアには触れて削る）。気づく距離は MonsterData.noticeRadius（仮: 18〜24m）。HP バーは体といっしょに浮く
- **ドライアド（森）**: いつも地面から0.3m（仮、floatHeight）浮いてゆっくり上下し、止まっていても腕と脚がゆらゆら揺れる。T の字の腕は下ろして漂わせる。勇者へ向かうときは前へ傾き、脚と腕を後ろへ流して、すいーっと滑るように進む。技は**木の葉の刃**: 右手を振りかぶって振り抜き、葉の刃を3枚、扇形（10度）に飛ばす（溜め0.55秒、秒速22m、1枚 Atk の50%、間隔2.6秒、すべて仮）。射程24m（魔法使いの通常攻撃28m より少し短い）。17m で止まり、10m より近いと下がる
- **ミイラ（砂漠）**: ゾンビのように体を左右に揺らし、頭がぐらぐらし、足を引きずってよろよろ歩く（速さが Spd の0.35〜1.15倍で波打つ、仮）。技1 **包帯**: 5〜16m の勇者へ右腕を振りかぶって（0.5秒）包帯を一本まっすぐ飛ばす（秒速34m）。当たると Atk の30% を与え、0.9秒スタンさせて手前まで引き寄せ、そのまま技2へつなぐ。外れると巻き戻す（間隔7秒）。技2 **つかみかかり**: 2.6m 以内の勇者へ両腕を振り上げて（0.45秒）振り下ろし、正面110度の勇者に Atk の140%（間隔2.2秒）。すべて仮
- **イフリート（砂漠）**: 炎の魔人。いつも0.35m（仮）浮いて上下し、炎の尾と組んだ腕がゆらゆら揺れる。技は**火球**: 両手を胸の前に出して合わせ、その間に火球（魔法使いの火球と同じ見た目）を作って0.9秒かけて大きく育て、前へ突き出して放つ（秒速18m、射程22m、Atk の120%、魔法、間隔3.4秒、すべて仮）。15m で止まり、9m より近いと下がる
- **ハーピー（山）**: ふだんは翼をたたんで鳥の足で歩く。勇者に気づくと勇者の半分くらいの高さ（0.9m、仮、hoverHeight）へ飛び上がり、羽ばたきながら間合いを保つ。飛ぶときは体を前へ傾け、脚は左右を揃えて後ろへ流し、翼は大きく上下に羽ばたいて先が遅れてしなる（大の字に広げない）。技は**羽根**: 飛んでいるときだけ、右の翼を後ろへ引いて振り抜き、羽根を一枚まっすぐ飛ばす（溜め0.45秒、秒速26m、射程24m、Atk の90%、間隔2.2秒、すべて仮）。16m で止まり、9m より近いと下がる
- **コカトリス（山）**: ふだんは翼をたたみ、首を前後に振りながら鶏のように歩く。勇者に気づくとハーピーと同じく0.9m 飛び上がって羽ばたく。技は**ダイブ**: 12m 以内の勇者へ向き直りながら4m まで舞い上がり（0.8秒）、勇者めがけて斜めに滑空して勇者の2.5m 先まで突っ込む（秒速17m）。通り道で体の1.8m 以内の勇者に1回ずつ Atk の150% とノックバック3m。0.9秒低いところにいてから戻る（間隔4.5秒、すべて仮）。8m で止まり、5m より近いと下がる

- 魔王ロビーを通らずに始めた試合（テストシーンなど）は、表の魔物がそのまま湧く

| バイオーム | 置ける通常魔物（2026-11-08） | 中ボス |
| --- | --- | --- |
| 森 | ゴブリン（BasicMob）, ドライアド | ウェンディゴ |
| 山 | ハーピー, コカトリス | ドラゴン |

- 上限: 魔物ごと・バイオームごとに MaxSpwn まで（仮: ゴブリン 10 / ドライアド・ミイラ・ハーピー 6 / イフリート・コカトリス 4）。倒すと SpwnCool のあと別の場所に湧き直す

#### 魔王の配置（魔王ロビーの地図、2026-11-08）

- **バイオームの札**（山・森・砂漠）: 通常魔物の枠が3つと中ボスの丸。枠を押すと、そのバイオームの候補と「空き」から選ぶ。同じ魔物を2枠に置くこともでき、その分だけ多く湧く（湧く上限 MaxSpwn が枠ごとに効く。3枠目は今の候補が2種類なので、重ねるか空けるかを選ぶ形。2026-11-08 に決定）。中ボスの丸を押すと置く・置かないを切り替える
- 中ボスを置かないバイオームは、広場にボスが出ず、その橋の結界も初めから開いている
- **橋の番人**: 地図の3本の橋のたもとの「番」を押すと、番人（ゴーレム）を置く・外す（橋ごとのオン・オフ。地図の好きな場所には置けない。2026-11-08 に決定）
- 最初の状態: 各バイオームの候補を順に置き、中ボスと番人はすべて置く。フィールド魔法は表の先頭から5つ
- 塔はすべて砂漠に立つので、塔のデッキ（塔の操作の窓で出せる魔物）は砂漠に置いた通常魔物。5本の塔の最初の魔物に順に割り振る（例: ミイラ・イフリート・ミイラ…）。砂漠に何も置かなければ砂漠の表の魔物
- 勇者でプレイする（魔王が BOT の）試合と、ロビーを通らない試合は、魔王ロビーの配置を使わない。自然湧きは表のまま、中ボスと番人は全部、塔は砂漠の魔物（今はイフリートとミイラ）
- 置いた内容は GameSession（PlacementChosen / BiomeMonsters / BiomeBossOn / BridgeGuardianOn / FieldSpells）に書く

#### 橋の番人（BridgeGuardian）

- 魔王城へ渡る3本の橋の前（橋のたもとから陸側へ10m、仮）に1体ずつ立つ。うろつきも進軍もしない。倒されると戻らない（仮。未定）
- 魔王は魔王ロビー／マッチロビーの地図で、橋ごとに番人を置く・外す。番人は MonsterData.isBridgeGuardian の魔物で、今はゴーレムだけ。デッキとは別枠でコストはかからない。ロビーを通らなければ全部の橋にゴーレムが立つ（BOT魔王でも同じ）

| ゴーレム（すべて仮） | 1200 | 30 | 15 | 5 | 4.5 | 400 | 5m |

- **行動**: 半径30m に勇者が来ると「！」を出して、すぐその勇者の方を向いて追う。持ち場から45m より遠い勇者はあきらめて持ち場に戻る。触れただけではダメージなし。のけぞり・ノックバックは無効（スタンは効く）
- **重い足どり**（GolemFootsteps）: 走りのアニメーションをほかの魔物の0.6倍（仮）の速さで流し、両足が浮く瞬間は体を下げて、いつもどちらかの足を地面に着ける。足が着くたびに体が0.18m（仮）ズシンと沈み、足元から土煙が上がり、20m（仮）以内の自分の勇者の画面が少し揺れる（近いほど強い）

  2. 振り下ろし 0.2秒: 前方2.6m の地面へ
  3. 叩いた瞬間: 小さな衝撃波（半径4m、Atk の50%）。35m（仮）以内の自分の勇者の画面が0.6秒（仮）大きく揺れ、土煙と土のかけらが上がり、地面が半径2m・深さ0.25m（仮）へこむ（地面を削る仕組み GroundDig を使う。同じ場所を何度も叩くと深くなり、最大は BalanceConfig.digMaxDepth）

  5. 剣山: 7回目（列の最後）は、真ん中に高さ1.35倍（仮）の太い槍、まわりに外へ傾いた槍を内と外の二重の輪に計14本（仮）、半径2.4m（仮）に真ん中から外へ順に突き出す。少し長く残る。半径2.4m に Atk の100%。1回の叩きつけで同じ勇者には1度だけ当たる（衝撃波・槍・剣山のどれか1つ）

#### 広場のボス（BossSpawner）

中立の大ボス。山の広場にドラゴン、砂漠の広場にスコーピオン、森の広場にウェンディゴが1体ずついる。勇者だけを襲い、魔王や魔物とは戦わない。倒すと大きな経験値が入る（ラストヒット100%、アシスト50%は魔物と同じ）。

- **出現**: 試合開始（準備フェーズのあと）に BossSpawner が出す。倒されると300秒後（仮、respawnSeconds）に同じ広場へまた出る。HP と攻撃は、出たときの魔王レベルの倍率（魔物と同じ MonsterStatMultiplier）で強くなる
- **狙う相手**: 広場の中心から一定の距離（ドラゴン34m・スコーピオン30m・ウェンディゴ30m、仮、aggroRadius）にいる、生きている勇者のうち一番近い者。誰もいない間は毎秒HPの2%（仮）回復する
- **HPバー**: 操作中の勇者がボスの広場（狙う範囲＋12m）にいると、画面上部の中央に名前とHPの大きなバーを出す（BossHealthBarUI）。頭上のバーはない
- **状態異常**: スタンで動きと技が止まる（ドラゴンは空中で羽ばたいたまま止まる）。スローは移動に効く。のけぞり・ノックバックは無効
- **BOT勇者**: 狩りの相手には選ばない（近くにいれば戦う）
- **待機の動き**（2026-11-08）: 勇者がいないあいだ、息をして、首を回してあたりを見回し、重心を左右に移す。数秒〜10秒ごとにしぐさをする（ドラゴン: 翼を広げて伸び・首を振る・尾を大きく振る、スコーピオン: 爪をカチカチ鳴らす・尾を高く上げて震わせる・両爪を振り上げて威嚇・足踏み、ウェンディゴ: 地面のにおいをかぐ・頭を振る・前足で地面をかく）。BossBase.Idle が共通の見回し・息・しぐさの時間を出す
- **結界**（BossGate、2026-11-08）: 3本の橋のたもとに魔法陣の結界を張る（StageMap.json の bossGates。橋の始点を中心に半径15m の弧で陸の側を囲み、両端は海岸の見えない壁に重ねる）。山の橋はドラゴン、砂漠の橋はスコーピオン、森の橋はウェンディゴを倒すまで、勇者は橋へ進めない。倒すと結界が解けて（光がはじけ、テープと光の幕が消え、柱が地面に沈む）「◯◯が倒れ、結界が解けた！」と出る。解けた結界は、ボスが復活しても戻らない。魔王は結界を素通りできる。BOT勇者は結界の先へ道を探さない（NavMesh を切り抜く）。結界に近づいた勇者には「魔法陣の結界が道をふさいでいる ── ◯◯を倒すと解ける」と出る。橋の番人（BridgeGuardian）は結界の内側（橋のたもと）に立っているので、結界が閉じているあいだは結界の外の勇者を狙わない
  - 見た目: 2.6m おきの石の柱（上に光る結晶）、柱の間に少したるませて張った紫のテープ2段（金の縁取りに小さな魔法陣と菱形のルーンの模様。模様はゆっくり流れる）、薄い紫の光の幕、結界の中の地面に大きな魔法陣（ゆっくり回る）。模様の絵は実行時に作る
- **モデル**: Tripo のモデルに骨を入れて取り込む（ArtSource/characters/build_dragon.py・build_scorpion.py・build_wendigo.py、共通処理は boss_rig.py）。クリップはなく、羽ばたき・脚・尾・爪はコード（BossRig）で骨を回して動かす

**ドラゴン**（DragonBoss / DragonData）: 戦うときは飛んでいて、地上には急降下のときだけ降りる。炎と急降下を交互に使う（技の間は2.2秒、仮）

- **休む**（2026-11-08）: 勇者が4秒（仮）いなければ広場の真ん中へ降りて、翼をたたんで休む。勇者に気づくと0.7秒（仮）で翼を広げて飛び上がり、旋回に戻る

- **旋回**: 広場の床から高さ20m、半径18m の円を秒速14m で回る。旋回では内側へ傾く。脚は後ろへたたむ
- **炎**: 勇者から水平に14m 離れた高さ13m の空中で止まり、首を反らす（1秒）→ 円すいの炎を2.4秒吐く（届く距離24m、半角16度）。炎は勇者を毎秒28度の速さで追う。0.3秒ごとに炎の中の勇者へ Atk の35%、さらに燃焼（3秒、0.3秒ごとに4の固定ダメージ）。岩や崖の陰には届かない
- **急降下**: 狙った勇者の足元に、縮んでいく赤い輪を1.3秒出す（最初の70%は勇者を追い、そのあと場所が決まる）→ 秒速48m でその地点へ突っ込む → 半径6m に Atk の160%、7m 吹き飛ばす → 地上に2.2秒とどまる（近接の勇者が殴れる隙）→ 1.6秒で旋回の高さへ戻る。勇者の体とはぶつからない（上に乗らないように）

**スコーピオン**（ScorpionBoss / ScorpionData）: 広場の中を秒速6m で歩いて勇者を追い（広場の外には出ない）、距離に合わせて3つの技から選ぶ。同じ技は続けて使わない（技の間は2.2秒、仮）

- **毒針**（8〜30m）: 尾を後ろへ引く（0.8秒）→ 振り下ろして毒の弾を3発、12度ずつ扇状に飛ばす（秒速26m、34m まで）。当たると Atk の60% と毒（5秒、0.3秒ごとに6の固定ダメージ）。地面や柱に当たるとはじける
- **突進**（7〜26m）: 脚で地面をかく（0.9秒、最初の75%は向き直る）→ 秒速26m で最大26m まっすぐ走る。広場の縁で止まる。ぶつかった勇者に Atk の130%、斜め前へ8m 吹き飛ばす → 硬直1.2秒
- **十字斬り**（20m 以内）: 両方の爪を広げて振り上げる（0.7秒）→ 前で交差させて振り下ろし（0.18秒）、X の形の斬撃（縦横6.4m）を前へ飛ばす（秒速22m、26m まで）。勇者は貫通して1人1回、Atk の100%。壁や柱に当たると消える

#### AI 挙動

- **うろつき**: 最終フェーズ（魔王Lv16、25:00）までは、まちへ向かわず、湧いた場所の周り（半径18m、仮）を歩いては止まる（1〜3.5秒、仮）
- **発見**: 半径20m 以内で、正面180度の視野（仮、monsterSightDegrees）に勇者が入ると、頭の上に黄色い「！」を出して追いかける。視野の外からでも攻撃されたら気づく。「！」が出たら、その勇者の方へすばやく向き直り（毎秒900度）、1.2秒のあいだは向いたまま追う（仮、BalanceConfig の monsterAlertFaceSeconds / monsterAlertTurnSpeed）。30m 離れると元に戻る
- **最終フェーズ**: 魔王Lv16になると、すべての魔物がはじまりのまちへ向かう

- **経路追従**: 最終フェーズに塔の魔物はウェイポイント（StageMap.json）に沿って、自然湧きの魔物はまっすぐ NavMesh でまちへ進む
- **ターゲット選択**: 基本は視野内（20m）で最も近い勇者を追う。ヘイト値による標的の変化は一部の賢い魔物（MonsterData の useHate）だけが持つ。現在の3種類はいずれも持たない
- **ヘイト値**: 賢い魔物は範囲内でヘイト最大の勇者を追い、全員0なら最も近い勇者を追う。今の標的のヘイトを1.1倍（仮）超えたら標的が変わる。増える条件: その魔物に与えたダメージ1につき+1、魔物の近く（仮20m）で味方を回復すると回復量×0.5（仮）。減る条件: 毎秒10%（仮）ずつ減る。死亡または20m（仮）より離れるとその勇者のヘイトは0
- **Taunt**: 範囲内の魔物にヘイト+100（仮）を加算する。ヘイトを持たない普通の魔物には効果なし
- **間合い**（2026-11-08）: 魔物は勇者に体が重ならない距離で止まり、勇者の方を向く（近接は 体の半径＋勇者の半径0.5m＋0.35m（仮、monsterKeepGap）。遠距離の魔物は MonsterData.keepDistance）。勇者が retreatDistance（未指定なら止まる距離の8割）より近づくと少し下がる。橋の番人も勇者に重ならないところで止まる。ボスは前から止まる距離を持っている
- **接触ダメージ**: 同じ魔物から 1秒に1回のみ。当たるたびに攻撃アニメーションを再生する。間合いで止まっても届く（接触の判定は半径1.5m）。自分の技で戦う魔物（ドライアドほか）は勇者に接触ダメージを与えない
- **見た目（MonsterData.modelPath）**: 指定があれば Knight スケルトンのモデルを表示し、走り・攻撃は勇者と共通のクリップ（仮）を使う。未指定なら prefab の Body のまま。現在は BasicMob のみゴブリン（Goblin/goblin、modelScale 0.8 は仮。右手に短剣、左手に木の盾）で、TankMob / FlyingMob は未差し替え
- **魔物の死亡演出**: モデルのある魔物はHP0で、攻撃と反対の斜め上へぶっ飛びながら白く染まり、不規則に膨らんで白い粒に破裂する（0.75秒、発射速度11m/s、粒50個、いずれも仮値。MonsterData）。経験値はHP0の瞬間に入り、金色の粒は破裂した地点から飛ぶ。飛んでいる間は攻撃せず、攻撃も受けない。モデルのない魔物はHP0で即座に消える
- **魔物の被弾の反応**: 攻撃を受けるたびに、ダメージに比例した小さなノックバックと極小のけぞりが入る。継続ダメージでは起きない。のけぞりは状態異常のスタンとは別物で、スタン耐性を作らない。効きやすさは MonsterData.hitReactionScale（0で無効）。仮値: ノックバック 1ダメージあたり0.03m・最大1.2m / のけぞり 1ダメージあたり0.006秒・最大0.25秒（BalanceConfig）/ TankMob は無効
- **StartTown 到達時の挙動**: `agent.isStopped=true` で停止。Destroy せず、接触ダメージで継続的にコアを削る
- **指揮官オーラ被付与**: 魔王半径10m 内で強化
- **FlyingMob ContactDamage 範囲**: 地上のコアに届くよう 6m に拡大（通常半径 1.5m）

### スポナー（Spawner）仕様

#### BasicSpawner

- HP=300, Atk=15, Cool=2（自動射撃間隔）
- Exp=100, MaxCost=10, Inv=3
- AttackRange=40, DetectRange=30
- MaxConcurrent=2（SpawnInterval は廃止し、湧き間隔は魔物ごとの SpwnCool に統一）

#### 機能

- inv の魔物を順に、魔物ごとの SpwnCool に従って湧かせる
- 半径30m 内の Hero を検知して 2秒間隔で射撃。見た目はてっぺんに水晶のある塔（高さ8m、仮）で、撃つ前に水晶が光りながら0.75秒（仮、SpawnerData.attackChargeSeconds）溜め、どす暗い紫の芯にピンクの炎をまとったレーザーを放つ（魔法攻撃で mDf が効く）。溜めの時間は2秒の間隔に含み、溜め始めに一番近かった勇者がいた場所へ撃つ（動いて避けられる。誰もいなくなっても撃つ）。レーザーの線上にいる勇者に当たる。自分の塔と魔物はレーザーをさえぎらない
- 破壊された塔は黒ずみ、水晶の光が消える
- 同時生存上限 2体
- 出現演出: 警告の円（外周から内側へ薄れるグラデーションの円。1.2秒）→ 闇のポータルが開く（0.9秒）→ 魔物がポータルの下から這い上がり、炎と煙の中から飛び出す（1.1秒）→ ポータルが閉じる。秒数と半径（1.4m）は仮値で BalanceConfig に置く
- 魔物の生成はポータルが開いた瞬間で、這い出している間は動かず、攻撃せず、攻撃も受けない（無敵）。SpwnCool は警告の円が出た時点から数え、演出中の魔物も同時生存上限に含める。スポナーが破壊されると、まだ魔物が出ていないポータルは閉じて取り消す
- HP=0 で機能停止（湧き・射撃停止、グレー化、残骸として残る）。復活・修復はしない
- 試合中に魔王が動的に魔物追加可能（俯瞰モード経由）

魔物の速さ・射程、MPのルール、魔物のうろつきなどはキャラのデータとコードを共有するので、3レーンでも新しい値で動く（速さと射程は広い地図に合わせて2倍のまま）。

**ウェンディゴ**（WendigoBoss / WendigoData）: 鹿の頭骨と角、黒い毛皮の獣。前かがみで四つ足をつき、広場の中を秒速6.5m（仮）で駆けて勇者を追う（広場の外には出ない）。同じ技は続けて使わない（技の間は2秒、仮）

- **雄叫び**: 勇者を初めて見つけると、まず体を起こして吠える（2.2秒）。その後は30秒（仮）ごとに技の候補に入る。勇者が8秒いなくなったら、次に見つけたときまた最初に吠える。吠えると、まわり45m（仮）の森にいる勇者に**森の呪い**をかける
- **森の呪い**（ForestCurse）: かかった勇者は森にいるあいだ、暗い霧で近くしか見えなくなる（霧は3m から濃くなり18m で見えなくなる、仮）。霧は1.2秒でかかり、森から出るか倒れると解けて1.6秒で晴れる。森の中の川や道を渡っても解けない。霧は自分の画面にだけかかる（BOT は呪われたことだけ分かる。BOT の視界を狭めるかは未定）
- **技の選び方**（2026-11-08）: 勇者が12m（仮）以上離れていれば大跳躍、近ければ近接の破壊攻撃（引っ掻きか叩きつけ）
- **大跳躍**（12〜38m、仮）: 身をかがめる（0.7秒）→ 勇者の方へ前に大きく跳ぶ。遠いほど高く長く飛ぶ（最大で高さ9m・1.1秒、近いと高さ約4m・0.66秒）。勇者の真上ではなく少し手前に降りる → 着地点の半径4m に Atk の140%、6m 吹き飛ばす。地面が少し削れて土煙と衝撃の輪が出る → 硬直0.9秒
- **引っ掻き**（12m 以内）: 片腕を前へ高く振り上げる（0.6秒、左右交互）→ 振り下ろす（0.22秒）。爪が前の扇形（約8m・110度）の勇者を薙いで Atk の100%、4m 吹き飛ばす。目の前の地面をはがし（半径2.2m・深さ0.5m 削れる）、瓦礫を9個、55度の扇状に前へ投げる（秒速20m、約24m 届く）。瓦礫は放物線を描いて回り、当たると Atk の55%（1個は1人に1回）。地面や木に当たると砕ける → 硬直0.8秒
- **叩きつけ**（12m 以内）: 後ろ足で立ち上がって両腕を高く振り上げる（0.85秒）→ 前の地面へ叩きつける（0.14秒）。前方150度の約10.6m、または叩きつけた所から7m 以内の勇者に Atk の160%、8m 吹き飛ばす。地面が大きく砕け（半径3.4m・深さ0.8m）、瓦礫10個がまわりへ飛び散る（約12m）→ 硬直1秒（数値はすべて仮）
- **モデル**: 元のモデルは後ろ足の片方を後ろへ伸ばしているので、ゲームでは反対の足の左右反転になるよう骨を回してそろえている

  - 森の広場（ウェンディゴの広場）: 森の道の上 (-115, -137.5) の半径24m の空き地（StageMap.json の forestPlaza。2026-11-08 に森の奥から道の上へ移し、小道はなくした）。縁に大きな枯れ木が26本ほど並び（高さ6〜13m、当たり判定あり）、道が通る北西と南東だけ空いている。床は暗い土と苔のまだらで、縁は苔むした石。骨（あばら骨と頭骨）、苔の生えた石、倒れた枯れ木が散らばる。広場と小道には巨大樹・木・シダ・しげみを生やさない
  - 森（左下）: 巨大樹の森。高さ24〜34mの巨大樹が約90本（間隔15m前後。太い幹と張り出した根、高い枝の先と頂上に大きな葉の傘）、そのすき間に高さ5〜10mの木が約510本（間隔4.6m）、足元にシダが約1500か所。幹に当たり判定があり魔法の弾や視線をさえぎる。平らなので重戦士や近接が動きやすい

- **川**:

  - 橋のたもとの結界: 「広場のボス」の結界を参照
- **魔王城の島**: 海の上空に浮かぶ（高さ30m、半径46m、中心 (167, -187)、いずれも仮）
- **吊り橋**: 山・砂漠・森それぞれの岸から1本ずつ、計3本（幅8m、長さ103〜135m）。岸から垂れ下がる曲線で登り、島の縁で傾き20度（仮）になる。手すりは腰の高さのロープで当たり判定がなく、踏み外すと海へ落ちて倒れる。両岸に門柱を立て、主ロープと吊りロープで踏み板を吊る。人（勇者・BOT・魔王・魔物）が乗ると、その人のまわりの主ロープと手すりが少し引かれて下がり（最大0.45m）、橋に沿って横揺れの波が伝わる（最大0.28m、乗った瞬間と歩いた距離で強まり、0.9秒で半分に収まる。BridgeRopeSway、いずれも仮）。踏み板と足元は動かさず、見た目だけ。魔物と BOT は NavMesh で渡れる。橋の手前にゴーレムが立つ
- **地面の凹凸**（2026-11-07）: 地面は2m 格子で、ほんの少し起伏がある（高さ±0.2m 程度。ゆるい波と細かい波の重ね合わせに、格子ごとのわずかなでこぼこ）。まち・川岸・スポナー・広場・橋のたもと・岩のまわり・山のふもと・地図の端は平らで、道は凹凸を半分にする。木や草や石は置いた場所の高さに合わせる。当たり判定も見た目と同じ形（Field_Ground のメッシュ）で、古い平らな Ground の当たり判定は切った。地面の高さは Resources/StageGround.bytes にも書き出し、地面を削る仕組みが使う
- **地形の性質（登り）**: 30度の登りで足が遅くなる割合（HeroClassData.slopeSpeedPenalty、仮）: 重戦士45% / 剣士20% / 魔法使い・僧侶15% / 魔王25%（demonKingSlopePenalty）。下りと平地は変わらない。TerrainWalker が勇者・BOT・魔王・魔物の速度に掛ける
- **作り直す手順**: StageMap.json か build_lowpoly.py を変えたら、Blender で LP_Field.fbx を書き出し（StageGround.bytes と StageMap_Sand.json も書き出される）→ 初回だけ Tools/LowPoly/Setup Field Import（浅瀬の水を半透明の材質へ差し替え、メッシュを読めるようにする）→ MainStage で Tools/LowPoly/Apply Stage Layout And Rebake NavMesh → シーン保存 → Title シーンで Tools/LowPoly/Bake Dig Data
- **地面を削る仕組み**: 地面だけを実際に削れるようにする（壁や建物は壊さない）。普段の地面の見た目は今のローポリのままで、削れた場所だけ切り抜いて土の面を見せる。ブロックの断面は見せない。
  - 見た目: フィールドそのものが削れて見えるようにする。立方体は使わず、格子の頂点を少しずらして三角形でつないだ、角ばった面で作る。滑らかにはせず、周りの低ポリに合わせた紙細工のような質感にする。参考: 『ドンキーコング バナンザ』のボクセル（格子の頂点からメッシュを作り、角を立てて形を見せる）。
  - 形: 段々のすり鉢状で、段の間は急な坂。輪郭はいびつな多角形。歩いてそのまま出られる。足場と坂で色を変え、深いほど湿って暗い土にする。穴のすぐ外も草がはがれて土が見える。
  - 削れるスキル: Stomp と Explosion のみ。削った跡は試合中戻らない。重ねて削ると深くなる（最大深さまで）。
  - 削れない場所: はじまりのまち、魔王城、スポナーの周り、木の周り、岩・壁・塔の周り、フィールドの外周。
  - 草は削れた部分だけ消える。NavMesh は作り直さず、魔物と BOT は足元の深さに合わせて体を上下させる（経路は変わらない）。
  - ネットワークでは「どこを、どの範囲、どの深さまで」だけ同期する。形はこの値だけで決まるので、どの端末でも同じ穴になる。
  - 仮値: 格子 0.75m / 1段 0.25m / 最大深さ 1m / Stomp 半径3m・深さ0.5m / Explosion 半径8m・深さ1m（どちらもスキルの大きさに合わせて広がる）/ 削れない幅: 岩・壁・建物・塔 1.5m、スポナー 4m、木 2m、外周 3m。BalanceConfig と SkillData に置く。
  - 木の位置は `Tools/LowPoly/Bake Dig Data` で GroundDigData に保存している。フィールドのモデルを作り直したら実行し直す。

### 試合終了の演出（MatchEndDirector、2026-11-08）

試合が決まったら、ゲームの時間を止めずに演出を流し、最後に勝敗の画面を出してからリザルトへ移る。演出は実時間で進む。

1. **カットイン**: 画面が白く（魔王の勝ちは暗い赤に）光り、ゲームがスロー（×0.12、仮）になる。斜めの布の帯が右から滑り込み、左に決めた者の肖像（ジョブの肖像。なければ「勇」「魔」の丸）と名前、右に大きな文字を出す（1.9秒）
   - 魔王撃破: 「最後の一撃！ / 魔王を討ち取った」（最後に攻撃した勇者）
   - 魔王城コア破壊: 「最後の一撃！ / 魔王城のコアを打ち砕いた」
   - はじまりのまちのコア破壊: 「はじまりのまち 陥落 / まちのコアが破壊された」
   - 時間切れ: 「時間切れ / 勇者たちは間に合わなかった」（スローにしない）
2. **消滅**: 演出用のカメラが魔王（またはコア）を正面斜め上から映してゆっくり回る。光の柱と衝撃の輪が立ち、0.7秒後に闇の粒がはじけて、魔王（コア）は縮みながら消える（3秒）。時間切れではまちのコアは消えない
3. **勝敗の画面**（VictoryScreen）: ゲームを止めて、布と紙の大きなリボンを出す。勇者の勝ちは紫の布に金の縫い目「勇者チームの勝利！」、後ろに回る金の光の筋と舞い落ちる金の星。魔王の勝ちは黒い布に暗い赤の縫い目「魔王軍の勝利」、赤黒い光の筋と舞い上がる火の粉。リボンの上の札に自分の側の「勝利」「敗北」、下の紙に一言（「魔王は討たれ、世界に光が戻った」「はじまりのまちは闇に呑まれた」など）。2秒後から「クリックで結果へ」、7秒で自動でリザルトへ
- リザルト（Result シーン）も同じ勝敗の画面に、成績の紙の札（倒した数・倒された数・アシスト・与ダメージ・被ダメージ・獲得経験値）と布の「タイトルへ戻る」ボタンを重ねる
- 古い文字だけの「勝者: 勇者チーム」の板（MatchResultUI）は出さない

  - MatchLobby: マッチング待機。上中央に開始までの時計（60秒。0で自動開始）、右下にワールド（押すたびに切り替え）と「準備完了」（下に準備できた人数 n / 5 人。自分も数える）
    - 勇者: 左に自分（3Dモデルと名札）と編成のまとめ（押すと勇者ロビーと同じ編成パネル）、右に勇者チーム（自分は金の縁、BOTは肖像・名前・ジョブ・「準備OK」のはんこ、空き枠は「マッチング中…」）と「VS」と魔王の札。ロジックは HeroSkillLoadout で共有。ジョブを変えると1〜4枠は新しいジョブの標準に戻り、5枠目は保持する（1〜4枠と同じスキルになる場合だけ共通スキルに戻す）
    - 魔王: 魔王ロビーと同じ編成の画面に、下の「相手の勇者」（4人の肖像・名前・ジョブ）
    - 編成のデータ（ジョブ・共通スキル・使える魔物・橋の番人・Cost 上限）はシーンの HeroLoadoutPanel / DemonLoadoutPanel が持つ。画面はコードで作る
  - MainStage: 本戦
  - Result: 戦績表示
  - Test_Sandbox / Test_DemonKing: 開発テスト用
- **MatchManager 状態遷移**: WaitingForStart → DemonPrepPhase（1分、SkipPrepPhase なら1秒） → InMatch（30分） → Finished

### UIデザインの方針

2026-11-06 にHUDのデザイン案（試合中HUDデザイン案。勇者の通常・戦闘中・スキルホイール、魔王の行動中・俯瞰、部品と色）で方向を決めた。

- **参考にしたもの**: 画面の構成は Dead by Daylight、見た目は A Hat in Time。魔王側の暗い色は Cult of the Lamb、魔王の俯瞰と編成の画面は Evil Genius 2（画面の構成）。俯瞰の地図の絵は、黄土色の紙に墨の線で描いた手描きの絵地図（2026-11-07 にユーザーが見せた参考画像。雰囲気だけを参考にする）。ほかの作品を参考にするときは、作品ごとに相談してから使う
- **見た目**: 布（フェルト）と紙の手作り風。縫い目の点線、やぶれた紙、リボン、マスキングテープ、白い縁のシール。勇者側は紫のフェルトとクリーム色の紙、魔王側は同じ作りを黒・暗い赤・骨色にする
- **配置（試合中）**:
  - 上中央: 残り時間の丸い時計。左に「はじまりのまち」、右に「魔王城コア」のHP。時計の下のリボンに、勇者側は魔王のLv、魔王側は次のLvまでの時間を出す。勇者側はコアの下に魔王のHPも出す
  - 右上: いる場所（はじまりのまち・砂漠・森・山・川・海・魔王城など）
  - 左下: 自分（大きな丸い肖像、Lv、HP・MP・Exp）。その上に味方3人（肖像・名前・HP）と、かかっている状態異常（名前と残り秒）
  - 右下: スキルカード5枚。キー番号、Lv、イラスト、名前、消費MP。選択中は浮き上がって金の縁。クールダウン中は幕と残り秒、MP不足はイラストを灰色にして消費MPを赤くする。選択中のスキルで減るMPはMPバーに斜線で示す
  - 中央下: その場で必要な案内だけ
- **色**: HP #ef5a55 / MP #a98bff（勇者・魔王共通。スキルカードの消費MPの札は #d9ccff）/ Exp #76dcb8 / はじまりのまち #2aa893 / 魔王城コア #9a45d6。勇者のフェルト #3a2a5e、紙 #f7e9c8、リボン #c9303a。魔王のフェルト #1b1116、紙 #eadfc8、リボン #8e1b22
- **文字**: 見出しと数字は Mochiy Pop One（仮決め。候補は Dela Gothic One / RocknRoll One / Potta One。どれも Google Fonts で商用利用可）
- **スキル名**: 画面では日本語の表示名（SkillData.displayName）を出す（仮決め）。skillName は処理の判定に使っているので英語のまま
- **作り**: 部品はコードで組み立てる（Scripts/UI/Hud。HudStyle に色・文字・部品、HudShape が角丸・円・リボン・やぶれた紙、HudStitch が縫い目、ThickOutline が文字の太い縁取り、HudBar がバー）。専用の HudCanvas（sortingOrder -1）に置き、リスポーンやリザルトなどほかのUIより奥に描く。布と紙の模様は ArtSource/ui/build_hud_textures.py で作る Resources/UI/HudFelt.png と HudPaper.png、文字は Resources/Fonts/MochiyPopOne-Regular.ttf
- **いる場所の決め方**: はじまりのまちの中心から40m以内（仮値）は「はじまりのまち」、魔王城の島は「魔王城」、海と川の深いところ（橋の上）は「橋」、浅瀬は「浅瀬」、それ以外は砂漠・森・山、どれでもなければ「草原」
- **未決定**: 文字の最終決定、スキルの日本語名、魔王スキル（内容が決まるまで「未定」の枠を出す）、魔王の肖像の絵
- **塔の並び**: 一覧は地図の北から（北西・北東・中央・南西・南東）
- **まだ古い見た目のもの**: 塔の操作の窓（SpawnerActionPopup）と魔物選び、スキルホイール、照準、パワーアイテムの通知、リスポーン・リザルト

2026-11-07 にロビーのデザイン案（UIデザイン案のロビーの段。情報一覧・タイトル・勇者ロビー・編成パネル・マッチロビー・魔王ロビー）で決めて、試合中HUDと同じ布と紙で作り直した。

- **魔物の印**: 魔王ロビー（通常魔物の枠・中ボス・橋の番人・魔物を選ぶ一覧）では、丸い布の中に魔物の丸いアイコン（MonsterData.icon / BossData.icon）を出す（2026-11-10）。今のアイコンは仮で、3D モデルを写したもの（Tools/Characters/Generate Monster Icons で作って割り当てる）。正式な絵は同じ欄に差し替える。アイコンのない魔物は色つきの丸い布に名前の1文字目
- **未決定**: 魔物の正式な絵、ユーザー名の入れ方、設定画面、ロビーの背景アート、魔物が増えたときの一覧のスクロール

### 操作（キーバインド）

デバッグ機能はすべてコマンド経由に統一されたため、以下のキーは実機能またはコマンド入力トリガーとしてのみ維持される。

- `1〜5`: スキルアップポイント消費（勇者）／フィールド魔法（魔王。左クリックで発動、右クリックでやめる）
- `W` を素早く2回押して押し続ける: ダッシュ（勇者。W を離すと終わる。移動速度1.6倍、2回押しの猶予0.3秒、いずれも仮値、BalanceConfig）
- `Backspace`: 落下時のみリスポーン
- **ConsoleUI 起動**: `/` または `Tab`
- **俯瞰モード**: `V`（魔王ロール時、Core 接触後にON/OFF）
- **その他通常操作**: `WASD`/マウス/左クリック（攻撃）/右クリックまたは E キー（スキル発動。E は Mac で右クリックしにくいための仮の割り当て）/左Shift長押し（スキルホイール）/`Esc`

## 6. デバッグコマンド

デバッグ機能は、旧キーバインド（T, X, N, B, F, Y, M, K, J, 9, 0など）をすべて削除し、ConsoleUI 経由のコマンドに統一された。

### ConsoleUI 操作

- `/`キー: 「/」入りの入力ボックスを表示（コマンド用）
- `Tab`キー: 空の入力ボックスを表示（チャット用）
- `Enter`: 実行 + 閉じる
- `Esc` / `Tab`（表示中）: 破棄 + 閉じる
